## Changes Made

### `nbody.cpp`
- **MPI**: Bodies are distributed as contiguous chunks across ranks. Each step uses `MPI_Allgatherv` to gather positions (only positions, minimizing communication), then each rank computes forces on its local bodies. Results are gathered back to rank 0 at the end.
- **CUDA**: Two kernels — `computeForcesKernel` with shared-memory tiling for the O(N²) force computation, and `computeEnergyKernel` for energy calculation. Shared memory tiles are loaded iteratively to fit all N bodies regardless of size.
- **OpenMP**: Parallelizes position extraction, body reconstruction, velocity updates, integration, and energy reduction on the host side.

### `CMakeLists.txt`
- Added CUDA language support with `nvcc` compilation
- Linked MPI, OpenMP, and CUDA runtime libraries
- Set CUDA architectures (70–89) for modern GPUs

### Parallelization Strategy
- **MPI** distributes work across nodes/ranks
- **CUDA** accelerates the compute-intensive force kernel on each GPU
- **OpenMP** parallelizes host-side data preparation and updates within each rank
