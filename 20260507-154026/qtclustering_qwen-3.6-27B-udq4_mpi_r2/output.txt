Now I have a clear picture of the codebase. Let me plan the MPI parallelization strategy and implement it.

The QT clustering algorithm's main loop tries every unclustered point as a seed and picks the one producing the largest cluster. Within each round, seed evaluations are independent — perfect for MPI parallelization.

Strategy:
1. Rank 0 generates data, broadcasts to all ranks
2. Each rank evaluates a subset of seeds independently
3. Two-phase MPI_Allreduce finds global best (max cardinality, min seed tiebreaker)
4. Winner rank broadcasts cluster members; all ranks update `clustered` array
5. Repeat until all points clustered
