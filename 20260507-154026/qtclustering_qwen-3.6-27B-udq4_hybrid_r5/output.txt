1. Generates synthetic 2D point data
2. Iteratively finds clusters by trying each unclustered point as a seed
3. For each seed, iteratively adds the closest point that maintains diameter < threshold

The key parallelization opportunities:
- **MPI**: Distribute seed candidate evaluation across ranks (each seed is independent)
- **OpenMP**: Parallelize seed evaluation within each rank
- **CUDA**: Accelerate the hot-path distance computation (max distance from each candidate to all cluster members)
