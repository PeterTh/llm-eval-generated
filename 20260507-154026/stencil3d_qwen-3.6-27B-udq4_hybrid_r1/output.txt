## Summary

Parallelized the 3D stencil benchmark using a **hybrid MPI + CUDA + OpenMP** approach:

### Parallelization Strategy
- **MPI**: Domain decomposition along Z-axis across MPI ranks, with ghost/halo layers exchanged via non-blocking `MPI_Isend`/`MPI_Irecv` at each iteration
- **CUDA**: 7-point stencil kernel and boundary copy kernel run on GPU for the interior computation per rank's subdomain; async halo uploads via `cudaMemcpyAsync` with separate streams
- **OpenMP**: Parallelized CPU-side operations (initialization, CPU fallback stencil, validation with reductions)

### Key Implementation Details
- **Z-axis decomposition**: Each rank owns a contiguous slice of Z planes plus 2 ghost layers (1 top, 1 bottom)
- **Double buffering**: Alternates between grid1/grid2 each iteration
- **Halo exchange**: After each stencil step, top/bottom halos are exchanged with neighbor ranks via MPI
- **Result gathering**: `MPI_Gatherv` collects all rank data on rank 0, then reconstructs the full global grid by extracting interior planes and global boundaries
- **GPU selection**: Round-robin GPU assignment across ranks
- **CPU fallback**: Gracefully falls back to OpenMP-only if no CUDA device is available
