## Summary

**Hybrid MPI + OpenMP + CUDA parallelization** of the matmul benchmark:

### Architecture
- **MPI**: 1-D row-block distribution of the output matrix C across ranks. Each rank owns a block of rows. Matrix B is broadcast to all ranks (needed for the row-block scheme). Results are gathered back to rank 0 via `MPI_Gatherv`.
- **CUDA**: Each MPI rank runs a tiled GEMM kernel (32×32 tiles with shared memory) on its local GPU. With 4 RTX 3090 GPUs, each rank maps to one GPU via `rank % numGPUs`.
- **OpenMP**: Matrix initialization uses `#pragma omp parallel for collapse(2)` for multi-threaded host-side data setup.
