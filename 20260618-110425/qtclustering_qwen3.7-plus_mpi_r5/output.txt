**Algorithm structure:**
- `qtClustering` has an outer loop that tries each unclustered point as a seed
- For each seed, `generateCandidateCluster` builds a candidate cluster independently
- The seed with the largest candidate cluster wins, its members get marked clustered
- This repeats until no more clusters can be formed

**MPI strategy:**
1. All ranks generate identical data (deterministic seed)
2. Distribute seed evaluations across ranks (stride-based)
3. MPI_Allreduce to find global best cluster (max cardinality, tie-break by position)
4. MPI_Bcast winning cluster members to all ranks
5. All ranks update state identically

**Performance optimizations:**
- Incremental distance updates in candidate generation (O(N·k) vs O(N·k²))
- Squared distances to avoid sqrt
- Preallocated working arrays
- `vector<char>` instead of `vector<bool>`
