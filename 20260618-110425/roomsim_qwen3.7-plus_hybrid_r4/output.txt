## 3. Algorithm: Radiosity-Based Room Impulse Response Simulation

The simulation models sound/light wave propagation between surfaces in a room through 4 phases:

1. **Mesh Generation**: Procedural icosphere (subdivided icosahedron) with inward-facing normals simulating a room
2. **Precomputation**:
   - **Form Factors (Kij)** — N×N matrix. For each triangle pair (i,j), Monte Carlo ray tracing (16 rays) with octree-accelerated visibility testing computes energy transfer
   - **Time Delays (Tau)** — N×N matrix. Distance between triangle centers divided by wave speed
3. **Wave Propagation**: T timesteps. At each timestep, each triangle accumulates reflected radiosity from all other triangles, delayed by Tau, weighted by Kij and area
4. **Distance Computation**: Cross-correlation of each triangle's radiosity signal against the source's signal to estimate propagation distance

## 4. Data Structures

| Structure | Description |
|-----------|-------------|
| `Vec3` | 3D vector with arithmetic ops, dot, cross, norm |
| `Triangle` | 3 `Vec3` vertices + cached normal, area(), center() |
| `Octree` | Spatial acceleration: up to 8 children per node, leaf stores triangle indices, supports ray-box test and `applyToTris` |
| `IcosphereMesh` | Generates subdivided icosahedron |
| `SimulationState` | Central state: `triangles`, `areas`, `rho`, `kij` (N×N), `tau` (N×N), `radE` (T×N), `radB` (T×N), `distances` (N) |

All matrices are **flat `std::vector` in row-major order** with helper index functions `idx2d(i,j)` and `idxTN(t,n)`.

- Each (i,j) pair is **independent** (except shared RNG state)
- Heaviest computation: ray tracing through octree, 16 samples per pair
- **Top parallelization candidate**

### B. `computeTimeDelays()` (lines 610-616) — **O(N²)**
```cpp
for (size_t i = 0; i < N; ++i)
    for (size_t j = 0; j < N; ++j)
        tau[i*N+j] = computeTau(triangles[i], triangles[j])
```
- Each (i,j) pair **completely independent**, trivial computation
- **Easily parallelizable**

### C. `runSimulation()` (lines 626-657) — **O(T×N²)**
```cpp
for (size_t t = 0; t < T; ++t)              // SEQUENTIAL - timestep dependency
    for (size_t i = 0; i < N; ++i) {        // PARALLELIZABLE within timestep
        val_t sumB = 0;
        for (size_t j = 0; j < N; ++j) {    // reduction into sumB
            // reads radB[t-tau, j] (past timesteps only)
            sumB += kij[i,j] * areas[j] * radB[t-tau, j];
        }
        radB[t, i] = rho[i] * sumB + radE[t, i];  // write to unique (t,i)
    }
```
- **t loop is sequential** (each timestep reads previous timesteps' `radB`)
- **i loop is parallelizable**: reads only from past timesteps, writes to unique `(t,i)`
- **j loop is a reduction** (sumB) — parallelizable with per-thread accumulators

### D. `computeDistances()` (lines 667-688) — **O(N×T²)**
```cpp
for (size_t i = 0; i < N; ++i)       // PARALLELIZABLE - independent per i
    for (size_t t = 0; t < T; ++t)   // cross-correlation
        for (size_t tt = t; tt < T; ++tt)
            sum += radB[tt, i] * radB[tt-t, sourceIndex]
```
- Each `i` is **completely independent**
- **Easily parallelizable**
