Initialization uses the same seed on every rank, so no broadcast is needed and the initial state is identical to the original.\n- **CUDA** does the heavy work: a shared-memory-tiled all-pairs force kernel (one thread per owned body, structure-of-arrays double-precision layout) plus a position-integration kernel. The kernel accumulates forces in the same ascending-j order as the original serial loop, keeping the semantics equivalent.\n- **OpenMP** parallelizes the CPU-side O(n²) validation pass (`computeTotalEnergy` with reductions, plus the finite/bounds checks).\n- CMake compiles the `.cpp` file as CUDA (`set_source_files_properties ... LANGUAGE CUDA`, so no new files), links `MPI::MPI_CXX`, `OpenMP::OpenMP_CXX`, and `m`, and builds for the native GPU architecture. I configured with `-DCMAKE_CUDA_HOST_COMPILER=g++-12` since CUDA 12.0 doesn't officially support the default GCC 13.\n\n**Correctness:** 1-rank and 4-rank runs produce bitwise-identical results (same output hash), including with uneven partitions (n=1000 over 3 ranks) and more ranks than bodies. Against a serial reference of the original code, results agree to ~13 significant digits; the tiny drift comes from CPU-vs-GPU FMA contraction differences, unavoidable in a GPU port. Validation (`-v`) passes with matching final energy.\n\n**Performance:** at n=32768, s=10 the original serial code takes ~79 s; one GPU takes 1.22 s (~65×).
