PARALLELIZATION APPROACH:
-------------------------

MPI Layer (Distributed Memory):
- Divides matrix rows among MPI processes
- Rank 0 initializes all data structures
- All ranks receive full vector and matrix via broadcast
- Each rank processes its assigned row partition
- Results gathered to rank 0 for validation/output
- Synchronization via MPI_Barrier for accurate timing

OpenMP Layer (Shared Memory):
- Applied to reference CPU computation
- Dynamic scheduling with chunk size 32
- Improves CPU performance for validation
- Used as fallback when CUDA unavailable

CUDA Layer (GPU Acceleration):
- Optimized kernel with 256 threads per block
- One thread per matrix row for coalesced access
- Automatic device selection: rank % num_gpus
- Efficient CSR format processing on GPU
- Synchronization with cudaDeviceSynchronize()
- Graceful fallback to OpenMP if CUDA unavailable

EXECUTION:
----------
Single node: 
  mpirun -np <N> ./spmv [options]

Multi-node:
  mpirun -np <N> -hostfile <hosts> ./spmv [options]

With OpenMP threads:
  OMP_NUM_THREADS=<T> mpirun -np <N> ./spmv [options]

All original command-line options preserved:
  -n <num>  : Matrix dimension
  -s <num>  : Sparsity factor
  -i <num>  : Iterations
  -m <val>  : Max value
  -v        : Enable validation
  -r        : Print results
  -h        : Help
