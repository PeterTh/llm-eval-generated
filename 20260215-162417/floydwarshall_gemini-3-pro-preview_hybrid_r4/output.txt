    *   **OpenMP Integration**: Used `#pragma omp parallel for` in `initializePathMatrix` (and implicitly in the sequential `initializeDistanceMatrix` per rank) for host-side initialization.
    *   **CUDA Integration**: Implemented a CUDA kernel `floydWarshallKernel` to offload the main computational loop. Each rank updates its local rows on the GPU.
    *   **Hybrid Algorithm**:
        *   The matrix is distributed by rows.
        *   In each iteration `k`, the owner of row `k` broadcasts it to all other ranks using `MPI_Bcast`.
        *   Each rank then launches a CUDA kernel to update its local portion of the matrix using the broadcasted row `k` (which is copied to the GPU).
    *   **Validation**: Updated `validateResult` to gather the distributed matrix to Rank 0 for validation against the original logic.
