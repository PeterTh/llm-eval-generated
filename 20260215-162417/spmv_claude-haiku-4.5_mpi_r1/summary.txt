## SpMV MPI Parallelization Summary

### Files Modified:
1. spmv/spmv.cpp - Added MPI parallelization
2. spmv/CMakeLists.txt - Added MPI configuration

### Key Implementation Details:

#### Parallelization Strategy:
- Row-based distribution: Each MPI process handles a contiguous block of matrix rows
- Process 0 (master) initializes the full sparse matrix and distributes work
- Load-balanced: Last process may handle slightly more rows if numRows is not evenly divisible

#### Communication Pattern:
1. Configuration broadcast (command-line arguments)
2. Dense vector broadcast (MPI_Bcast) - needed by all processes
3. CSR structure scatter (MPI_Send/MPI_Recv) - variable-sized per process
4. Result gathering (MPI_Gatherv) - collect computed rows

#### Computation:
- Each process independently computes spmvCpu on its local rows
- No inter-process communication during computation (embarrassingly parallel)
- Timing measured across all processes with MPI_Barrier synchronization

#### Validation:
- Reference computation done on rank 0 only (or all if more efficient)
- Final results gathered and validated on rank 0
- Maintains correctness across multiple processes

### Performance Optimizations:
- High optimization flags: -O3 -march=native
- Efficient MPI collective operations
- Minimal communication overhead through careful design
- Barriers only for synchronization, not data movement during computation
