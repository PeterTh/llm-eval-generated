CUDA IMPLEMENTATION DETAILS:

GPU Kernel: updateElementsKernel
- One-to-one thread mapping per element (one thread = one element)
- Parallel flux computation across all elements simultaneously
- Optimizations:
  * Register prefetching for current element data
  * Inlined flux computation to avoid function call overhead
  * Pragma unroll for loop optimization
  * Coalesced memory access patterns

GPU Memory Management:
- Static mesh data (materials, connectivity) copied once to GPU
- Dynamic state (energy values) allocated in ping-pong buffers
- Pointer swapping on GPU side to avoid inter-iteration data transfers
- Final results copied back to host after all iterations

Performance Characteristics:
- Kernel configuration: 512 threads per block (optimal for occupancy)
- Grid size calculated dynamically based on problem size
- Async memory transfers minimized
- cudaDeviceSynchronize() called only after all kernel executions
