### roomsim.cpp - Hybrid MPI+OpenMP+CUDA parallelization
1. **MPI**: Added `MPI_Init/Finalize`, rank/size distribution. All ranks build the same mesh/octree. MPI distributes triangle rows across ranks for form factors, time delays, and distances. Uses `MPI_Allgatherv` to synchronize results.

2. **OpenMP**: `#pragma omp parallel for` with `schedule(dynamic,1)` for form factor computation (load-balanced since ray tracing varies per pair) and `schedule(static)` for time delays (uniform work).

3. **CUDA**: Two GPU kernels:
   - `simulationKernel`: Computes wave propagation per timestep. Each thread handles one triangle's radB accumulation. After each timestep, results are synchronized via MPI across ranks, then uploaded back to GPU for the next timestep.
   - `distanceKernel`: Cross-correlation for distance estimation. Each thread handles one triangle independently.

4. **Correctness**: Deterministic per-(i,j) RNG seeding ensures reproducible results regardless of parallelization configuration. `Vec3` and `Triangle` methods annotated with `__host__ __device__` for CUDA compatibility. Output/validation only from rank 0.
