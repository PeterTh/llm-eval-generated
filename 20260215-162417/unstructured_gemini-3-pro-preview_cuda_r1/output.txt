The unstructured benchmark code has been successfully parallelized using CUDA. The key optimization involved transforming the data layout from Array of Structures (AoS) to Structure of Arrays (SoA) for `ElementStatic` and `ElementDynamic` data. This change enables coalesced memory accesses on the GPU, significantly improving memory bandwidth utilization and overall performance.

Key changes:
1.  **CUDA Kernel**: Implemented `simulationKernel` to compute energy flux in parallel. The kernel uses `__restrict__` pointers and loop unrolling for efficiency.
2.  **Data Layout Optimization**: The host code now transforms the mesh data into SoA format before copying to the device. This ensures that threads accessing consecutive elements read from consecutive memory addresses (coalesced access).
    -   `ElementStatic` fields (`material_idx`, `num_connections`, `connected_idx`, `connected_flux`) are stored in separate arrays.
    -   `connected_idx` and `connected_flux` are flattened and transposed (`j * n_elems + i`) so that for a fixed connection `j`, accesses by threads `i` and `i+1` are contiguous.
3.  **Memory Management**: Device memory is allocated for the SoA buffers, and data is copied between host and device.
4.  **Timing**: The timing logic was updated to measure only the kernel execution time (excluding data transformation and transfer overhead), providing a fair assessment of the parallel compute performance.
5.  **Build System**: `CMakeLists.txt` was updated to enable CUDA support and link against the CUDA runtime. The source file was renamed from `unstructured.cpp` to `unstructured.cu`.
