Summary of changes:
1.  **`cholesky/CMakeLists.txt`**: Added `find_package(MPI REQUIRED)` and linked `MPI::MPI_CXX` to the executable.
2.  **`cholesky/cholesky.cpp`**: Rewrote the implementation to use MPI.
    *   **Data Distribution**: The matrix is distributed using a 1D column-cyclic distribution ($P_k$ owns columns $j$ where $j \pmod P = k$).
    *   **Algorithm**: Implemented a parallel Cholesky decomposition where the owner of column $k$ computes the diagonal element and broadcasts the normalized column to other processes, which then update their local trailing submatrices.
    *   **Initialization**: Rank 0 generates the full matrix (to ensure identical input to the sequential version for correctness) and scatters it to other processes.
    *   **Validation**: Rank 0 gathers the resulting factor $L$ and performs validation against the original matrix.
    *   **Output**: Maintains the same output format and performance reporting (GFLOPS).

The code has been verified to compile and run correctly with MPI on multiple processes (tested with 2 and 4), passing validation checks even with odd matrix sizes.
