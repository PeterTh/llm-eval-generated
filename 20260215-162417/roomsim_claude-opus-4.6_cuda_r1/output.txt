The CUDA parallelization is complete. Here's a summary of changes:

**CMakeLists.txt**: Enabled CUDA language, set `LANGUAGE CUDA` on the .cpp file, added CUDA-specific optimization flags (`--use_fast_math`), updated to C++17 for CUDA compatibility.

**roomsim.cpp**: Four CUDA kernels parallelize all compute-intensive phases:
1. **`computeFormFactorsKernel`** — one thread per (i,j) triangle pair (N² threads), with per-pair deterministic RNG and iterative flat-octree traversal for ray blocking
2. **`computeTimeDelaysKernel`** — one thread per (i,j) pair
3. **`runSimulationStepKernel`** — one thread per triangle, launched once per timestep (timesteps are sequential due to data dependencies)
4. **`computeDistancesKernel`** — one thread per triangle

Key infrastructure changes: Vec3/Triangle got `__host__ __device__` qualifiers; the recursive Octree is flattened into GPU-friendly arrays (`FlatOctreeNode` + index array); a device-side xorshift32 RNG replaces the host `mt19937`.

**Results**: Identical output hash for N=320, validation passes at all sizes (320, 1280, 5120). ~14x speedup at N=320 (1050ms→73ms).
