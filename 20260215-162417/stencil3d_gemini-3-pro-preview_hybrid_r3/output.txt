The `stencil3d` benchmark has been parallelized using a hybrid MPI + CUDA approach, with OpenMP enabled for host-side operations.

1.  **MPI Decomposition**: The 3D grid is decomposed along the Z-axis (slowest varying dimension). Each MPI rank manages a slab of the domain plus halo (ghost) layers for boundary exchange.
2.  **CUDA Offloading**: The core stencil computation (`stencilKernel`) and grid initialization (`initializeGridKernel`) have been moved to CUDA kernels. Double buffering is used on the GPU (`d_grid1`, `d_grid2`) to avoid race conditions.
3.  **Halo Exchange**: After each iteration, boundary layers are copied from Device to Host, exchanged via MPI (Isend/Irecv), and copied back from Host to Device to update the ghost cells.
4.  **OpenMP**: OpenMP pragmas are used in the validation step to parallelize the check on the host.
