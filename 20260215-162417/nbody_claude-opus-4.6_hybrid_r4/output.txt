**CMakeLists.txt**: Enables CUDA, MPI, and OpenMP. Uses `set_source_files_properties` to compile the `.cpp` file as CUDA, with `--use_fast_math` and `--expt-relaxed-constexpr` for performance.

**nbody.cpp** — Three-level parallelism:

1. **MPI** (inter-node): Bodies are distributed across ranks. Each rank owns `N/P` bodies. `MPI_Allgatherv` exchanges positions every timestep; `MPI_Gatherv` collects velocities at the end.

2. **CUDA** (GPU): The O(N²) force computation uses a shared-memory tiled kernel (`computeForcesKernel`) — each thread computes forces on one local body against all N bodies, loading tiles of positions into shared memory for coalesced access. A separate `integrateKernel` updates positions. Both use `__launch_bounds__` for occupancy optimization.

3. **OpenMP** (CPU threads): Used for the validation loop and the O(N²) potential energy computation with `reduction(+:energy)` and `schedule(dynamic, 64)` for load balancing.
