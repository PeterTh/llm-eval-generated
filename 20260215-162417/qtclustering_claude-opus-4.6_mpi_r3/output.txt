**qtclustering.cpp** — Key MPI parallelization changes:
1. **MPI Init/Finalize** in `main()` with rank-guarded output (only rank 0 prints)
2. **Precomputed distance matrix** — all ranks compute the same O(N²) matrix once, eliminating redundant `sqrt` calls during clustering
3. **Distributed seed evaluation** — in `qtClustering()`, unclustered seeds are distributed round-robin across ranks; each rank evaluates its subset independently
4. **Global reduction** — `MPI_Allreduce` with `MPI_MAXLOC` on encoded `{cardinality*(N+1) - seed_index, rank}` finds the globally best cluster with deterministic tie-breaking (max cardinality, then min seed index)
5. **Broadcast** — winning rank broadcasts cluster members and seed via `MPI_Bcast`; all ranks update state identically
6. **Early-exit optimization** in `findClosestPoint` — skips candidates as soon as any distance exceeds threshold or current best
7. **Reusable buffers** for `in_cluster` and `members` vectors to avoid repeated allocation
