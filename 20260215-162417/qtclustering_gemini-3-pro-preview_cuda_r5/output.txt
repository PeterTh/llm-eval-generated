The implementation uses a hybrid approach where the computationally intensive task of finding the best cluster size for each seed point is offloaded to the GPU, while the CPU handles the high-level orchestration and validation.

Key optimizations include:
1.  **Memory Coalescing**: The memory layout for cluster members was restructured to ensure coalesced global memory access by threads in the warp.
2.  **Shared Memory**: Points and cluster status are cached in shared memory to reduce global memory traffic.
3.  **Bitmask Optimization**: A register-based bitmask is used to track cluster membership within the kernel, eliminating repeated global memory reads for the `in_cluster` check. This supports up to 4096 points per cluster.
4.  **Squared Distances**: Expensive square root operations were removed from the inner loop by comparing squared distances.
5.  **Efficient Data Transfer**: Only necessary data (cluster sizes) is transferred back to the host, and `cudaMemcpy2D` is used to efficiently retrieve the members of the best cluster.
