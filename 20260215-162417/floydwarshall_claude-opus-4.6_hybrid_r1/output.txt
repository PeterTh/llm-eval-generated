The Floyd-Warshall benchmark has been parallelized with a hybrid MPI+OpenMP+CUDA approach:

- **MPI**: Distributes matrix rows across ranks; each iteration broadcasts the k-th row from its owner, then gathers results to rank 0
- **CUDA**: Each rank offloads its local rows to GPU; a 2D kernel with shared memory for the k-row tile updates all (i,j) pairs in parallel per iteration
- **OpenMP**: Parallelizes CPU-side validation (diagonal check and triangle inequality) with `collapse(2)` and critical sections

Key optimizations: pinned host memory for fast GPU transfers, shared memory for broadcast k-row tile, coalesced memory access pattern (threads along j dimension), and 2D thread blocks (32×8).
