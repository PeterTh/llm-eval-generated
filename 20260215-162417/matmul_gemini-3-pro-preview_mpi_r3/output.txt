The matrix multiplication benchmark has been parallelized using MPI and optimized with cache blocking.

### Changes Made
1.  **CMakeLists.txt**: Added `find_package(MPI REQUIRED)` and linked the `matmul` target against `MPI::MPI_CXX` to enable MPI support.
2.  **matmul.cpp**:
    *   **MPI Initialization**: Added `MPI_Init`, `MPI_Comm_rank`, and `MPI_Comm_size`.
    *   **Data Decomposition**: Implemented row-wise decomposition of matrix A across MPI ranks. Each rank computes a specific chunk of rows of the result matrix C. Matrix B is replicated on all ranks (initialized independently to avoid communication).
    *   **Parallel Initialization**: Modified initialization to be parallel. Each rank generates its own portion of matrix A and the full matrix B using the deterministic pseudo-random number generator, eliminating the need for initial data distribution.
    *   **Blocked Matrix Multiplication**: Replaced the naive triple loop with a cache-blocked implementation (tiling) to improve cache locality and performance. The block size is set to 64.
    *   **Result Gathering**: Implemented `MPI_Gatherv` to collect the distributed results to rank 0 for validation and output.
    *   **Timing**: Updated timing to use `MPI_Wtime()` and `MPI_Barrier()` for accurate parallel performance measurement. Rank 0 reports the maximum computation time across all ranks.
    *   **Validation**: Confined validation logic to rank 0 after gathering the full result matrix.

### Performance & Scalability
*   **Scalability**: The code scales with the number of MPI processes by dividing the work (rows of A) evenly.
*   **Memory Efficiency**: Each rank only allocates memory for its local chunk of A and C, plus a copy of B.
*   **Computation**: The core kernel uses blocking to maximize cache reuse.
