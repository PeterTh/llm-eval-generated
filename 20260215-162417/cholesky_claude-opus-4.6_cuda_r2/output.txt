**cholesky.cpp**: Replaced the sequential `choleskyDecomposition` with a GPU-accelerated **blocked right-looking Cholesky** using 4 custom CUDA kernels:
1. **`factorDiagBlock`** — Factors a small diagonal block (up to 32×32) in shared memory using a single thread block
2. **`solvePanel`** — Forward substitution for the panel below the diagonal block, with each thread handling one row independently using shared memory for the diagonal block
3. **`updateTrailing`** — Rank-B symmetric update of the trailing submatrix using tiled shared-memory GEMM (the dominant O(n³) computation, highly parallel)
4. **`zeroUpper`** — Zeros the upper triangular part
