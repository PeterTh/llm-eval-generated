The MPI parallelization is complete. Here's a summary of the changes:

**CMakeLists.txt**: Added `find_package(MPI REQUIRED)` and linked `MPI::MPI_CXX`.

**floydwarshall.cpp** — key changes:
- **Row-block distribution**: The N×N matrix rows (i-dimension) are divided evenly across MPI ranks, with remainder rows distributed round-robin to early ranks.
- **Scatter/Gather**: Rank 0 initializes the distance matrix and scatters contiguous row blocks to all ranks via `MPI_Scatterv`. Results are gathered back with `MPI_Gatherv` only when needed for output/validation.
- **Parallel Floyd-Warshall**: For each iteration k, the rank owning row k broadcasts it via `MPI_Bcast`, then all ranks update their local rows — exploiting the fact that row k and column k values are read-only during iteration k.
- **Local path init**: Path matrix is initialized directly on each rank (path[i][j] = i) without scatter, saving communication.
- Only rank 0 prints output, validates, and reports results.
