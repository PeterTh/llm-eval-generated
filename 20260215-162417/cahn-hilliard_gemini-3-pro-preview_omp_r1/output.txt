The Cahn-Hilliard benchmark code has been parallelized using OpenMP for shared-memory multicore execution.

### Changes Made:
1.  **CMake Configuration**: Updated `CMakeLists.txt` to find and link the OpenMP library (`find_package(OpenMP REQUIRED)` and `target_link_libraries(... OpenMP::OpenMP_CXX)`).
2.  **Parallelization Strategy**:
    *   Added `#pragma omp parallel` around the main time-stepping loop in `main` to create a single parallel region for the entire simulation, minimizing thread creation/destruction overhead.
    *   Applied `#pragma omp for collapse(2) schedule(static)` to the nested loops in `computeChemicalPotential` and `cahnHilliardUpdate` to distribute the 3D grid computation across threads. The `collapse(2)` clause increases the number of parallel tasks by flattening the loop nest, improving load balancing.
    *   Added `#pragma omp single` around the `std::swap(cold, cnew)` call to ensure buffer swapping is performed by only one thread while others wait at the implicit barrier.

### Performance Results:
The parallel implementation demonstrates good scalability on the test environment:
*   **1 Thread**: ~228 MCellUpdates/s
*   **2 Threads**: ~456 MCellUpdates/s (2.0x speedup)
*   **4 Threads**: ~723 MCellUpdates/s (3.17x speedup)
*   **Verification**: The code passed numerical validation (`-v`) with parallel execution.

Note: The default execution uses all available threads (which was 256 in the environment), but optimal performance was observed with a smaller number of threads (e.g., 4) for the tested grid sizes due to overhead or resource contention. The code is now fully capable of utilizing multicore CPUs via the `OMP_NUM_THREADS` environment variable.
