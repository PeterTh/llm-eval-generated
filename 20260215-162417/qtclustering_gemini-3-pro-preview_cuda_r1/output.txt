The QT clustering benchmark has been successfully parallelized with CUDA. The implementation uses a custom CUDA kernel to parallelize the search for candidate clusters, which is the most computationally intensive part of the algorithm.

### Changes Made:
1.  **`qtclustering/CMakeLists.txt`**:
    *   Enabled CUDA language support.
    *   Configured CUDA standard (C++17 compatible).
    *   Set `qtclustering.cpp` to be compiled as CUDA code.
    *   Added compilation options for optimal performance (`-O3`).

2.  **`qtclustering/qtclustering.cpp`**:
    *   Included `<cuda_runtime.h>`.
    *   Implemented `clustering_kernel` which computes candidate clusters for all potential seed points in parallel.
    *   Optimized memory access in the kernel using coalesced access patterns for the cluster membership checks (`my_in_cluster` array) and member lists (`my_members` array).
    *   Replaced the sequential `qtClustering` function with a CUDA-accelerated version that:
        *   Allocates GPU memory.
        *   Copies data to the device.
        *   Iteratively launches the kernel to find the best cluster.
        *   Updates the clustered status on the GPU.
        *   Retrieves the best cluster members from the GPU.
    *   Removed the now unused sequential helper functions (`findClosestPoint` and `generateCandidateCluster`).

### Performance Results:
*   **Original Sequential**: ~5000 ms for 1000 points.
*   **CUDA Parallel**: ~1170 ms for 1000 points (~4.3x speedup).
*   **Scaling**: ~5072 ms for 2000 points (consistent with algorithmic complexity, showing good utilization).
