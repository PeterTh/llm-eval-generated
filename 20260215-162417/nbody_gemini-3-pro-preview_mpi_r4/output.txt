The `nbody` benchmark has been parallelized using MPI with a non-blocking ring communication pattern to maximize performance and scalability.

**Changes made:**
1.  **`nbody/nbody.cpp`**:
    *   Initialize MPI environment (`MPI_Init`, `MPI_Finalize`).
    *   Distribute bodies among MPI processes using `MPI_Scatterv`.
    *   Implement a **ring communication algorithm** for force computation:
        *   Each process computes forces between its local bodies and a circulating buffer of remote bodies.
        *   Uses **non-blocking communication** (`MPI_Isend`, `MPI_Irecv`) to overlap communication with force computation for maximum performance.
    *   Implement parallel reduction for validation (`MPI_Allreduce`) and result gathering (`MPI_Gatherv`).
    *   Ensure rank 0 handles I/O and command-line arguments, broadcasting them to other ranks.
