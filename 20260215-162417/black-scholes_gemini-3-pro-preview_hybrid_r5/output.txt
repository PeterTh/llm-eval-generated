I have parallelized the Black-Scholes benchmark using a hybrid approach combining MPI, OpenMP, and CUDA.

1.  **MPI (Message Passing Interface):** Used to distribute the workload (number of options) across multiple processes/nodes. Each rank calculates its portion of the options.
2.  **OpenMP:** Used to parallelize the data generation (`generateOptions`) on the host CPU.
3.  **CUDA:** Used to offload the core Black-Scholes pricing computation (`blackScholesKernel`) to the GPU. The data is copied to the device, processed in parallel, and results are copied back.

**Changes made:**
-   Modified `CMakeLists.txt` to include MPI, OpenMP, and CUDA support, and to treat `.cpp` files as CUDA source files.
-   Modified `black_scholes.cpp` to:
    -   Initialize MPI and OpenMP.
    -   Implement a CUDA kernel `blackScholesKernel` and `__device__` helper functions.
    -   Distribute the option pricing workload among MPI ranks.
    -   Generate options in parallel using OpenMP.
    -   Execute the pricing kernel on the GPU.
    -   Gather results from all ranks to rank 0 using `MPI_Gatherv`.
    -   Perform validation on rank 0.

The implementation ensures that the validation passes and the results are consistent with the original serial code (accounting for floating-point differences and the original code's specific parameter mapping). The executable name remains `black_scholes`.
