### Parallelization Strategy

- Process 0 initializes data and broadcasts the input vector to all processes
- Matrix rows are scattered to processes (each gets roughly numRows/size rows)
- Each process independently computes its assigned rows of the output vector
- Results are gathered back to process 0 for validation and output
- Load balancing handles uneven distributions (numRows % size extra rows)
