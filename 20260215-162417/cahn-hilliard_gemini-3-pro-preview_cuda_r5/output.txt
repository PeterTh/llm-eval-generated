The Cahn-Hilliard benchmark has been parallelized using CUDA. The implementation moves the core computational kernels (`computeChemicalPotential` and `cahnHilliardUpdate`) to the GPU, utilizing global memory for the concentration fields (`c`, `mu`) and optimizing for parallel scalability.

### Changes Made
*   **`cahn_hilliard.cpp`**: Rewritten to use CUDA.
    *   Implemented `__global__` kernels for chemical potential calculation and the Cahn-Hilliard update step.
    *   Converted `computeLaplacian` and `idx3` to `__device__` functions.
    *   Added CUDA memory management (`cudaMalloc`, `cudaMemcpy`, `cudaFree`).
    *   Maintained the original double-precision arithmetic and clamped boundary conditions.
*   **`CMakeLists.txt`**: Updated to enable CUDA language support and link against the CUDA runtime.

### Verification
The solution was verified by building and running the simulation.
*   **Validation**: The built-in validation passed (`-v`), confirming that concentration values remain within the expected bounds, preserving the semantics of the original CPU code.
*   **Performance**: On a larger grid (256x256x256), the implementation achieved **~3.2 GCellUpdates/s**, demonstrating effective GPU parallelization.

cd cahn-hilliard
