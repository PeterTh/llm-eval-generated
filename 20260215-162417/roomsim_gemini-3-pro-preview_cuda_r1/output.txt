The `roomsim` benchmark has been parallelized using CUDA for GPU acceleration. The following changes were made:

1.  **Updated `CMakeLists.txt`**: Added CUDA language support, specified CUDA standard (C++14) and architecture (compute capability 7.5+), and set `roomsim.cpp` to be compiled as a CUDA source file.

2.  **Modified `roomsim.cpp`**:
    *   Included `<cuda_runtime.h>` and added error checking macro `CHECK_CUDA`.
    *   Annotated `Vec3` and `Triangle` structs with `__host__ __device__` to allow usage on both CPU and GPU.
    *   Added device pointers to `SimulationState` and implemented `allocateDevice`, `copyToDevice`, `copyFromDevice`, and `freeDevice` methods for memory management.
    *   Implemented CUDA kernels for:
        *   `computeTimeDelaysKernel`: Parallelizes time delay calculation for all triangle pairs.
        *   `computeFormFactorsKernel`: Implements a brute-force ray casting approach on GPU (O(N^3)) to compute form factors, replacing the CPU Octree implementation. This scales well for the benchmark sizes and utilizes massive parallelism.
        *   `runSimulationStepKernel`: Parallelizes the wave propagation step over all triangles for each time step. The time loop remains on the host to ensure causality.
        *   `computeDistancesKernel`: Parallelizes the cross-correlation distance estimation for all triangles.
    *   Updated host functions (`computeTimeDelays`, `computeFormFactors`, `runSimulation`, `computeDistances`) to launch the corresponding CUDA kernels and manage data transfers.
    *   Updated `main` function to allocate GPU memory, copy initial data, and retrieve results for validation.

The implementation maintains correctness (verified against the original CPU implementation's validation checks) and significantly improves performance by leveraging GPU parallelism for the computationally intensive parts (form factor computation and wave propagation). The brute-force approach for form factors avoids complex Octree porting while providing sufficient performance for typical benchmark problem sizes.
