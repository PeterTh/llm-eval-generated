The `qtclustering` benchmark has been parallelized using OpenMP to accelerate the core clustering loop.

### Changes Made

1.  **Parallel Search for Best Cluster Seed**:
    -   The main bottleneck, searching for the seed that produces the largest cluster, was parallelized using `#pragma omp parallel` and `#pragma omp for`.
    -   Each thread computes a local best candidate (cardinality and seed index) to minimize critical section updates.
    -   A final reduction combines local results to find the global best cluster for each iteration.
    -   Deterministic tie-breaking (preferring smaller seed indices) was implemented to ensure results match the sequential version.

2.  **Thread Overhead Reduction**:
    -   The `#pragma omp parallel` region was moved *outside* the main `while` loop. This avoids the significant overhead of creating and destroying thread teams for every cluster found (which happens O(N) times).
    -   Synchronization is handled using `#pragma omp single` and implicit barriers to update the global state (removing clustered points) safely.

3.  **Memory Allocation Optimization**:
    -   Refactored `generateCandidateCluster` to accept pre-allocated scratch vectors (`in_cluster` and `members`) instead of allocating new vectors in every call.
    -   Thread-local scratch buffers are reused across iterations, drastically reducing memory allocation overhead, which is critical for performance.

4.  **CMake Configuration**:
    -   Updated `CMakeLists.txt` to find and link the OpenMP library (`OpenMP::OpenMP_CXX`).

### Performance

-   **Small N (500)**: Reduced execution time from ~433ms to ~145ms (~3x speedup).
-   **Large N (2000)**: Reduced execution time from >30s (estimated) to ~740ms.
-   **Correctness**: Validated that the parallel version produces valid clusters and identical results to the sequential baseline (verified with `-v` flag).

### Usage

The executable name remains `qtclustering`. The parallel version is built by default:

```bash
mkdir build && cd build
cmake ../qtclustering
make
./qtclustering -n 2000 -t 2.0
```
