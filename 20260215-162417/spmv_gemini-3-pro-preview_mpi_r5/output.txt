The `spmv` benchmark has been parallelized using MPI. The implementation distributes the matrix and vector among MPI processes, performing the sparse matrix-vector multiplication in parallel.

### Summary of Changes

1.  **`spmv/spmv.cpp`**:
    *   Added MPI initialization (`MPI_Init`) and finalization (`MPI_Finalize`).
    *   Implemented matrix distribution: Each process is responsible for a chunk of rows (`startRow` to `endRow`).
    *   Modified `initRandomMatrix` to generate the matrix structure (CSR format) locally for the assigned rows while maintaining the same random sequence as the serial version (by simulating the RNG state).
    *   Updated `fill` to support skipping random values, allowing each process to generate its portion of the `val` array correctly aligned with the global random sequence.
    *   Modified `main` to:
        *   Determine local row ranges based on MPI rank.
        *   Initialize local data structures.
        *   Perform the SpMV computation locally.
        *   Gather the results to rank 0 using `MPI_Gatherv` for validation and output.
        *   Compute the reference solution (for validation) only on rank 0.

2.  **`spmv/CMakeLists.txt`**:
    *   Added `find_package(MPI REQUIRED)`.
    *   Linked the executable against `MPI::MPI_CXX`.

### Verification results
The parallel implementation was verified against the serial reference solution (computed on rank 0) and passed validation with 1, 2, and 4 processes. The output correctly matches the expected behavior.

### Usage
To build and run the parallel version:
```bash
mkdir build && cd build
cmake ../spmv
make
mpirun -n <num_processes> ./spmv [options]
```
