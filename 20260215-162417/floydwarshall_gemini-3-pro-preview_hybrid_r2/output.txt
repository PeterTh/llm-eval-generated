The Floyd-Warshall benchmark has been parallelized using a hybrid approach combining MPI, OpenMP, and CUDA.

### Summary of Changes

1.  **`floydwarshall/floydwarshall.cpp`**:
    *   **MPI Integration**: Implemented a 1D row block decomposition where each MPI rank owns a subset of the graph's rows. Ranks broadcast the pivot row `k` at each iteration using `MPI_Bcast`.
    *   **CUDA Acceleration**: Offloaded the core matrix update kernel ($D_{ij} = \min(D_{ij}, D_{ik} + D_{kj})$) to the GPU. Each rank manages device memory for its local rows and executes the CUDA kernel for updates.
    *   **OpenMP Usage**: Used OpenMP for thread-level parallelism during the validation phase to speed up the $O(N^3)$ triangle inequality check.
    *   **Initialization**: Replicated the serial random number generation logic across all ranks to ensure identical input data without complex parallel RNG synchronization, while only storing the relevant local rows.

2.  **`floydwarshall/CMakeLists.txt`**:
    *   Updated to find and link **MPI** and **OpenMP**.
    *   Enabled **CUDA** language support.
    *   Configured `floydwarshall.cpp` to be compiled as a CUDA source file (`PROPERTIES LANGUAGE CUDA`) so that `nvcc` is used for compilation.

The resulting implementation leverages MPI for distributed memory parallelism across nodes, CUDA for massive parallelism within each node (on GPUs), and OpenMP for auxiliary CPU tasks, meeting the requirement for a hybrid approach on an accelerator cluster.
