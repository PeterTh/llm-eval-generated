The `roomsim` benchmark has been parallelized using a hybrid MPI + OpenMP + CUDA approach.

### Changes Made:
1.  **CMake Configuration**: Updated `roomsim/CMakeLists.txt` to enable CUDA language support and find/link MPI and OpenMP packages.
2.  **MPI Integration**: The simulation domain (triangles) is decomposed across MPI ranks. Each rank is responsible for computing form factors ($K_{ij}$), time delays ($\tau_{ij}$), and radiosity updates ($B_i$) for a subset of triangles.
3.  **OpenMP Parallelism**: The computationally intensive precomputation steps (`computeFormFactors` and `computeTimeDelays`) are parallelized using OpenMP on the CPU within each MPI rank. This accelerates the ray-tracing visibility checks which are difficult to port to GPU without significant refactoring of the recursive Octree structure.
4.  **CUDA Acceleration**: The main simulation loop (`runSimulation`) and distance estimation (`computeDistances`), which involve dense matrix operations, are offloaded to the GPU using custom CUDA kernels (`runSimulationKernel` and `computeDistancesKernel`).
5.  **Data Management**:
    -   Geometry (`triangles`, `octree`) is replicated on all nodes for visibility checks.
    -   Interaction matrices (`kij`, `tau`) are distributed by rows across MPI ranks.
    -   Simulation state (`radB`) is synchronized at each timestep using `MPI_Allgatherv` to ensure correct propagation of radiosity between domains.
    -   `Vec3` and `Triangle` structures were annotated with `__host__ __device__` to allow their use in CUDA kernels.

The resulting program uses MPI for inter-node scaling, OpenMP for intra-node CPU parallelism (ray tracing), and CUDA for GPU acceleration (matrix simulation), providing a comprehensive hybrid parallel implementation.
