The hybrid MPI+OpenMP+CUDA parallelization is complete. Here's a summary of the changes:

**CMakeLists.txt**: Enables CUDA language, finds MPI and OpenMP, compiles `roomsim.cpp` as CUDA via `set_source_files_properties`, passes OpenMP flags through `-Xcompiler`.

**roomsim.cpp** parallelization strategy:
- **MPI**: Distributes triangle rows across ranks for form factors, time delays, and distance computation. Uses `MPI_Allgatherv` to synchronize results.
- **OpenMP**: `#pragma omp parallel for` on form factor computation (dynamic scheduling for load balance with ray tracing) and time delay computation (static scheduling for simple work).
- **CUDA**: GPU kernels for wave propagation (`wavePropagateKernel` - one thread per triangle per timestep) and distance cross-correlation (`distanceKernel` - one thread per triangle). Simulation is replicated on each rank's GPU to avoid per-timestep MPI communication.

Key design decisions:
- Per-row deterministic RNG seeding (`42 + i`) enables parallel form factor computation
- Round-robin GPU assignment (`rank % num_devices`) for multi-GPU clusters
- Only rank 0 prints output; all ranks participate in computation
