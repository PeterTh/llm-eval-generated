The `qtclustering` benchmark has been parallelized using a hybrid approach combining MPI and OpenMP.

**Summary of Changes:**

1.  **MPI Integration:**
    *   Added MPI initialization and finalization.
    *   Rank 0 reads command-line arguments and broadcasts them to all other ranks.
    *   Rank 0 generates synthetic data and broadcasts the points array to all ranks.
    *   The outer loop over unclustered points (seeds) is distributed among MPI ranks.
    *   `MPI_Allreduce` is used to find the global maximum cluster size and the best seed across all ranks.
    *   A deterministic tie-breaking strategy (preferring the smallest seed index) is implemented to ensure consistent results across runs.

2.  **OpenMP Integration:**
    *   Within each MPI rank, the local chunk of candidate seeds is processed in parallel using OpenMP (`#pragma omp parallel for schedule(dynamic)`).
    *   Each thread maintains its own best local candidate cluster to avoid race conditions.
    *   A critical section (`#pragma omp critical`) is used to update the rank-local best candidate.

3.  **CMake Configuration:**
    *   Updated `CMakeLists.txt` to find and link against MPI and OpenMP libraries.
    *   Ensured correct compiler flags and include directories are set.

**Performance Considerations:**
*   **MPI:** Effectively distributes the workload of evaluating different seeds across multiple nodes/processes.
*   **OpenMP:** Exploits shared-memory parallelism within each node to further speed up the seed evaluation process.
*   **CUDA:** Was considered for the `findClosestPoint` function but determined to be inappropriate for this specific algorithm and problem size (default N=1000). The iterative nature of cluster growth (adding one point at a time based on current members) would require frequent host-device communication or complex kernel management that would likely degrade performance compared to the efficient CPU-based parallelization of the outer loop. The "maximum parallel performance" is best achieved here by saturating CPU cores with independent seed evaluations.

**Usage:**
The program can be compiled and run as follows:
```bash
mkdir build && cd build
cmake ..
make
mpirun -n <num_processes> ./qtclustering -n <num_points> -t <threshold> -v
```
