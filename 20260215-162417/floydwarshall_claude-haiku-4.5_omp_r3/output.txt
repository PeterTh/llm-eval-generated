   - The inner i and j loops are parallelized using `collapse(2)` to treat them as a single loop nest for better work distribution across threads

### 2. **CMakeLists.txt**

## Key Design Decisions for Performance & Scalability

1. **Loop Collapse**: Using `collapse(2)` on the nested i and j loops creates a single parallel region with n² iterations, enabling better load balancing across all available CPU cores
2. **Static Scheduling**: `schedule(static)` provides minimal synchronization overhead suitable for uniform work distribution 
3. **Barrier Synchronization**: The implicit barrier at the end of each k-iteration ensures correctness while allowing loop rebalancing
4. **No External Dependencies**: OpenMP is a standard compiler feature available in GCC/Clang
