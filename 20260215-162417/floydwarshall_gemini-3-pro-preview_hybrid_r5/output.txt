The Floyd-Warshall benchmark has been parallelized using a hybrid approach combining MPI, OpenMP, and CUDA:

1.  **MPI (Distributed Memory):** The distance matrix is distributed across MPI ranks using a 1D row-block decomposition. Each rank owns a contiguous set of rows. At each step `k`, the owner of the `k`-th row broadcasts it to all other ranks using `MPI_Bcast`.
2.  **CUDA (GPU Acceleration):** The core computational kernel (`dist[i][j] = min(...)`) is offloaded to the GPU. Each rank copies its local portion of the matrix to the GPU. The broadcasted `k`-th row is also copied to the GPU at each step. A CUDA kernel processes the updates in parallel.
3.  **OpenMP (Shared Memory):** Initialization and validation routines on the host CPU are parallelized using OpenMP (`#pragma omp parallel for`) to reduce overhead outside the main loop. The compiler flags include `-fopenmp` (passed to both host and device compilers).

The `CMakeLists.txt` file was updated to detect and link MPI, OpenMP, and CUDA, and to compile the `.cpp` file as CUDA code (`-x cu`).

To compile and run (example):
```bash
mkdir build && cd build
cmake ../floydwarshall
make
mpirun -np <num_ranks> ./floydwarshall -n 1024
```
