        *   Used `MPI_Reduce` and `MPI_Bcast` for validation and result aggregation.

        *   Implemented `computeTauKernel` to compute time delays on the GPU.
        *   Implemented `runSimulationKernel` to perform the wave propagation update on the GPU. This kernel handles the complex dependency on historical radiosity values.
        *   Implemented `computeDistancesKernel` to perform cross-correlation distance estimation on the GPU.
    *   **OpenMP Parallelism**:
        *   Parallelized the computationally intensive `computeFormFactors` function on the CPU using OpenMP. This function performs ray casting against the Octree (which remains on the CPU for complexity reasons).

    *   **Memory Management**: Implemented efficient host-to-device transfers, only copying necessary data and keeping the simulation state resident on the GPU where possible.
