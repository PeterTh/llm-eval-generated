=== Black-Scholes Hybrid Parallelization Implementation Summary ===

PARALLELIZATION APPROACH:
========================

1. MPI (Message Passing Interface)
   - Distributes option batches across multiple compute nodes/ranks
   - Uses MPI_Scatterv for efficient distribution of input data
   - Uses MPI_Gatherv for efficient collection of results
   - Provides coarse-grain parallelism for distributed computing

2. OpenMP (Open Multi-Processing)
   - Parallelizes option pricing within each MPI rank
   - Uses #pragma omp parallel for simd for loop-level parallelism
   - Dynamic scheduling with chunk size 256 for load balancing
   - Provides fine-grain parallelism for multi-threaded execution

3. CUDA Support
   - Application framework includes placeholder for CUDA acceleration
   - Ready for GPU integration via OpenMP target offloading
   - Optimizations in CMakeLists.txt support CUDA compilation if toolkit is available

OPTIMIZATION TECHNIQUES:
=======================

1. Code-level optimizations:
   - Reduced redundant sqrt() and exp() calculations
   - Caching intermediate values (sqrtT, sigmaSqrt, etc.)
   - Computation reordering for better numerical stability
   - SIMD-friendly innermost loop structure

2. Compiler optimizations:
   - -O3: Aggressive optimization
   - -march=native -mtune=native: CPU-specific optimizations
   - -ffast-math: Relaxed floating-point precision for performance
   - -fno-signed-zeros -fno-trapping-math: Arithmetic simplifications
   - -frename-registers: Enhanced register allocation
   - Interprocedural optimization (LTO)

3. MPI Communication optimization:
   - Efficient collective operations (Scatterv/Gatherv) instead of point-to-point
   - Single synchronization point for timing measurement
   - Minimized communication overhead
