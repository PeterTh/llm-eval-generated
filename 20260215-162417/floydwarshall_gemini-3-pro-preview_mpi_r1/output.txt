    *   Included `<mpi.h>`.
    *   Updated `main` to initialize MPI, determine rank/size, and distribute workload.
    *   Modified `initializeDistanceMatrix` and `initializePathMatrix` to only generate and store rows assigned to the local process, while maintaining the same random number sequence as the sequential version for correctness.
    *   Updated `floydWarshall` to use a 1D row block distribution. In each iteration `k`, the owner of row `k` broadcasts it to all other processes using `MPI_Bcast`.
    *   Optimized the algorithm by skipping updates when `dist[i][k]` is `INF`.
    *   Optimized the inner loop by removing a conditional check (`if (dist[k][j] == INF)`) to allow for better compiler vectorization.
    *   Implemented a gather step (`MPI_Gatherv`) at the end to collect the full matrix on rank 0 for validation and result printing, ensuring the original validation logic works correctly.

**Performance & Scalability:**

*   **Memory Scalability**: The distance and path matrices are distributed across processes (except during validation on rank 0), allowing the program to handle larger problem sizes as the number of nodes increases.
*   **Computation**: The parallel implementation distributes the `O(N^3)` workload across `P` processes. The critical path involves `N` broadcasts of size `N`.
*   **Vectorization**: The inner loop is branch-free for better SIMD performance.
