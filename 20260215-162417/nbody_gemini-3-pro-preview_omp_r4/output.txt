2.  **nbody/nbody.cpp**:
    -   Included `<omp.h>`.
    -   Added `#pragma omp parallel for schedule(static)` to the `computeForces` function. The outer loop over bodies is parallelized, and each thread computes the force on a distinct body `i` independently. The inner loop over `j` is read-only for positions, so there are no race conditions. `schedule(static)` is used because the workload is perfectly balanced (each body interacts with all other bodies).
    -   Added `#pragma omp parallel for schedule(static)` to the `integrateBodies` function. Each body's position update is independent.
    -   Added `#pragma omp parallel for reduction(+:energy)` to the kinetic energy calculation loop in `computeTotalEnergy`.
    -   Added `#pragma omp parallel for schedule(dynamic) reduction(+:energy)` to the potential energy calculation loop in `computeTotalEnergy`. `schedule(dynamic)` is used here because the loop is triangular (inner loop depends on outer loop index), causing load imbalance with a static schedule.
