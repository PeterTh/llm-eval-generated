2.  **Modified `cahn-hilliard/cahn_hilliard.cpp`**:
    *   Replaced CPU-based simulation functions (`initializeConcentration`, `computeChemicalPotential`, `cahnHilliardUpdate`) with CUDA kernels (`__global__` functions).
    *   Implemented `computeLaplacian` as a `__device__` function for use within kernels.
    *   Updated `main` function to:
        *   Allocate device memory for concentration (`c`, `cnew`) and chemical potential (`mu`) arrays.
        *   Execute the simulation loop entirely on the GPU.
        *   Perform memory transfers between host and device only for initialization and final result retrieval.
        *   Use an optimized block size of `(32, 4, 4)` to align with GPU warp execution.
