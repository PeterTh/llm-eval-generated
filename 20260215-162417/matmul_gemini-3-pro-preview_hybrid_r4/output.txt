The task was to parallelize the matrix multiplication benchmark using a hybrid approach combining MPI, OpenMP, and CUDA.

I have performed the following modifications:
1.  **Modified `matmul/CMakeLists.txt`**:
    *   Added `find_package(MPI REQUIRED)` and `find_package(OpenMP REQUIRED)`.
    *   Set the language property of `matmul.cpp` to CUDA so it compiles with `nvcc`.
    *   Added `OpenMP` and `MPI` libraries to `target_link_libraries`.
    *   Added compiler options for CUDA compilation (including passing `-fopenmp` to the host compiler).

2.  **Modified `matmul/matmul.cpp`**:
    *   Replaced the serial implementation with a hybrid parallel implementation.
    *   **MPI**: Handles the distribution of the computation across multiple nodes. The implementation uses a 1D row decomposition for matrix A and C. Rank 0 initializes the matrices, broadcasts matrix B to all ranks, scatters rows of A, and gathers rows of C.
    *   **OpenMP**: Parallelizes the matrix initialization and the result validation on the host (CPU).
    *   **CUDA**: Offloads the computationally intensive matrix multiplication to the GPU. A tiled matrix multiplication kernel (using shared memory) is implemented for efficiency. Data is transferred between host and device memory for each rank's local chunk of the matrix.

The resulting application compiles with CMake and utilizes MPI for inter-node communication, OpenMP for intra-node CPU parallelism, and CUDA for GPU acceleration, meeting all requirements.
