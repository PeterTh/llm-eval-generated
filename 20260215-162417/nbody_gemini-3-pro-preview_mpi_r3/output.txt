**Changes made:**

1.  **`nbody/CMakeLists.txt`**: Added `find_package(MPI REQUIRED)` and linked the executable against `MPI::MPI_CXX`.
2.  **`nbody/nbody.cpp`**:
    *   Added MPI initialization (`MPI_Init`, `MPI_Finalize`) and rank/size determination.
    *   Implemented data distribution: The total number of bodies is divided among MPI processes. Rank 0 initializes all bodies (to ensure deterministic results matching the serial version) and broadcasts them.
    *   Created an MPI derived datatype (`MPI_BODY`) to efficiently communicate the `Body` struct (position and velocity).
    *   Modified the main simulation loop:
        *   Each process computes forces and updates positions for its assigned subset of bodies (`myStart` to `myEnd`).
        *   `MPI_Allgatherv` is used at the end of each step to synchronize the updated body states across all processes, ensuring that every process has the full state required for the next force calculation step.
    *   Ensured that only Rank 0 performs output and validation.

The resulting program unconditionally uses MPI and produces identical results to the serial version, verified for various process counts and body numbers (including non-divisible counts). Performance is optimized by using `MPI_Allgatherv` with `MPI_IN_PLACE` to minimize memory copies.
