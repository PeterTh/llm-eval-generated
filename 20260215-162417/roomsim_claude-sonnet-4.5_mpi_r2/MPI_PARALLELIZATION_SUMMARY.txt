MPI Parallelization of RoomSim Benchmark
=========================================

IMPLEMENTATION SUMMARY
----------------------
Successfully parallelized the roomsim benchmark using MPI for distributed memory cluster parallelism.

Key Changes:
1. Updated CMakeLists.txt to find and link MPI libraries
2. Modified roomsim.cpp to:
   - Include MPI headers
   - Initialize/finalize MPI in main()
   - Distribute work across MPI ranks using row-wise domain decomposition
   - Use MPI collectives for communication (Bcast, Allreduce, Reduce)

Parallelization Strategy:
- Each rank handles a subset of triangles (rows in the computation matrix)
- Form factor computation: Embarrassingly parallel, each rank computes its local rows
- Simulation phase: Requires Allreduce at each timestep to share radiosity values
- Distance computation: Each rank computes distances for its local triangles

BUILDING AND RUNNING
--------------------
Build:
  cd roomsim
  mkdir build && cd build
  cmake ..
  make

Run:
  mpirun -np <num_processes> ./roomsim [options]
  
Example:
  mpirun -np 4 ./roomsim -n 320 -t 50 -v -o

The program unconditionally uses MPI (no serial fallback).
