The cahn-hilliard benchmark has been parallelized using MPI with a 1D domain decomposition along the Z-axis.

**Summary of Changes:**

1.  **`cahn-hilliard/CMakeLists.txt`**: Added `find_package(MPI REQUIRED)` and linked the executable against `MPI::MPI_CXX`.

    *   Added MPI initialization (`MPI_Init`) and finalization (`MPI_Finalize`).
    *   Implemented domain decomposition: The global Z-dimension (`nz`) is split among MPI ranks. Each rank handles a `local_nz` slice.
    *   Added ghost layers (halos) to the top and bottom of the local data arrays (`cold`, `cnew`, `mu`) to store neighbor data. Array size is `nx * ny * (local_nz + 2)`.
    *   Implemented `exchange_halos` function to swap boundary planes between neighboring ranks using `MPI_Sendrecv`. This handles periodic or internal boundaries, while global boundaries are clamped (Neumann conditions) locally on Rank 0 and Rank Size-1.
    *   Updated `initializeConcentration` to initialize only the local portion of the global domain, ensuring the same random values are generated as in the serial version by calculating the correct global linear index.
    *   Updated `computeLaplacian` to use ghost layers for stencil operations instead of conditional checks, improving performance.
    *   Updated `computeChemicalPotential` and `cahnHilliardUpdate` loops to iterate over the local domain (`1` to `local_nz`).
    *   Added `MPI_Gatherv` logic in `main` to gather the final concentration field to Rank 0 for validation and result printing.
    *   Performance metrics now report the total cell updates per second across all ranks.

**Performance & Scalability:**
The 1D decomposition minimizes communication overhead (only 2 neighbors per rank) and allows for contiguous memory transfers for the halo exchange. Correctness has been verified by comparing results across 1, 2, and 4 MPI ranks.
