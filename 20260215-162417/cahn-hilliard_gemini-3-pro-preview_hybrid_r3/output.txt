The Cahn-Hilliard benchmark has been successfully parallelized using a hybrid MPI + OpenMP + CUDA approach for maximum performance on accelerator clusters.

### Parallelization Strategy
1.  **MPI (Distributed Memory):** Implements domain decomposition along the Z-axis. The 3D grid is split into slabs assigned to different MPI ranks. Halo exchange (ghost cell communication) is performed between neighboring ranks for both the concentration field (`c`) and the chemical potential (`mu`) at each time step to handle stencil dependencies.
2.  **CUDA (GPU Acceleration):** The computationally intensive stencil operations (`computeLaplacian`, `computeChemicalPotential`, `cahnHilliardUpdate`) are offloaded to the GPU as CUDA kernels. This provides massive parallelism for the grid updates.
3.  **OpenMP (Shared Memory):** Used for parallel initialization of the concentration field on the host before copying to the device, ensuring the setup phase scales with core count.
