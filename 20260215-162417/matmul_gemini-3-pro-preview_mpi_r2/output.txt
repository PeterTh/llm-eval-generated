**Summary of changes:**

1.  **`matmul/CMakeLists.txt`**:
    *   Added `find_package(MPI REQUIRED)` to locate the MPI library.
    *   Updated `target_link_libraries` to link `matmul` against `MPI::MPI_CXX`.

2.  **`matmul/matmul.cpp`**:
    *   Replaced the serial implementation with an MPI-based parallel implementation.
    *   **Initialization**: Rank 0 broadcasts the matrix size `N`. Matrix `B` is initialized on all ranks to avoid broadcasting a large amount of data (computation vs communication trade-off). Matrix `A` is distributed: each rank initializes only the rows it is responsible for.
    *   **Computation**: The outer loop over rows of `A` is distributed among MPI processes. Each process computes a block of rows of the result matrix `C` (`local_C`).
    *   **Data Gathering**: `MPI_Gatherv` is used to collect the results from all processes back to rank 0. It handles cases where `N` is not perfectly divisible by the number of processes.
    *   **Validation**: Rank 0 performs the validation and printing of results, consistent with the original program's behavior.
    *   **Performance**: The implementation scales with the number of MPI processes, as verified by running with 1 and 4 processes.

The executable name remains `matmul` and the usage is unchanged. The program now unconditionally uses MPI for execution.
