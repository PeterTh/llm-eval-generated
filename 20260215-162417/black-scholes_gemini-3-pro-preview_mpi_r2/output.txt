The Black-Scholes benchmark has been parallelized using MPI. The implementation divides the option pricing workload across available MPI processes.

**Key Changes:**
1.  **MPI Initialization:** Added `MPI_Init`, `MPI_Comm_rank`, and `MPI_Comm_size` to setup the parallel environment.
2.  **Data Decomposition:** The total number of options is divided among processes. Each rank calculates its start index and count, handling any remainder to ensure all options are processed.
3.  **Local Generation:** `generateOptions` was modified to generate only the specific subset of options required by each rank, avoiding the need to scatter data from the root process and saving memory.
4.  **Parallel Execution:** Each rank computes prices for its local options independently.
5.  **Synchronization:** `MPI_Barrier` is used before and after the computation loop to ensure accurate timing of the parallel execution.
6.  **Result Gathering:** `MPI_Gatherv` collects results from all ranks to the root process (rank 0) only when validation or result printing is requested.
7.  **CMake Update:** Updated `CMakeLists.txt` to find and link the MPI library (`MPI::MPI_CXX`).
