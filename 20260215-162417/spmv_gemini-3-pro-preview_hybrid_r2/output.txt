The `spmv` benchmark code has been parallelized using a hybrid approach combining MPI, OpenMP, and CUDA.

**Changes made:**

1.  **CMakeLists.txt**:
    *   Enabled CUDA language support and set `CMAKE_CUDA_ARCHITECTURES` to `60`.
    *   Added `find_package` for MPI and OpenMP.
    *   Configured `spmv.cpp` to be compiled as CUDA source using `set_source_files_properties`.
    *   Added `-Xcompiler=-fopenmp` to pass OpenMP flags to the host compiler during CUDA compilation.
    *   Linked against MPI and OpenMP libraries.

2.  **spmv.cpp**:
    *   **MPI**: The application now initializes MPI. Rank 0 handles command-line arguments and matrix generation. The input vector is broadcast to all ranks. The matrix rows are distributed among ranks using `MPI_Scatterv` (for non-zero values/columns) and `MPI_Bcast` (for row delimiters). Results are gathered back to Rank 0 using `MPI_Gatherv`.
    *   **CUDA**: A CUDA kernel `spmvKernel` was implemented to perform the sparse matrix-vector multiplication on the GPU. Each MPI rank offloads its portion of the matrix multiplication to the GPU.
    *   **OpenMP**: Added `#pragma omp parallel for` to the CPU reference implementation (`spmvCpu`) and the verification function (`verifyResults`) to speed up initialization and validation steps on the host.

**Parallelization Strategy:**
*   **Data Distribution**: The matrix rows are partitioned across MPI ranks. Each rank is responsible for computing a segment of the output vector. The input vector `x` is replicated on all ranks (broadcast) since the random sparsity pattern might require access to any element of `x`.
*   **Computation**: The local SpMV computation on each rank is performed on the GPU using CUDA.
*   **Verification**: The root rank gathers the full result vector and verifies it against a CPU-computed reference solution (parallelized with OpenMP).

**Build Instructions:**
The project can be built using the standard CMake workflow (ensure `nvcc` is in your PATH):
```bash
mkdir -p spmv/build
cd spmv/build
cmake ..
make
```

**Run Instructions:**
Run with `mpirun`:
```bash
mpirun -np <num_ranks> ./spmv [options]
```
