The Cahn-Hilliard benchmark has been parallelized using a hybrid MPI + OpenMP + CUDA approach.

### Changes Made

1.  **`cahn-hilliard/CMakeLists.txt`**:
    -   Updated to use **MPI**, **OpenMP**, and **CUDA**.
    -   Set C++ standard to C++17 and CUDA standard to C++17.
    -   Added `CUDA_SEPARABLE_COMPILATION` and configured compiler options for performance (e.g., `-O3`, `-arch=sm_70`).

2.  **`cahn-hilliard/cahn_hilliard.cpp`**:
    -   Replaced serial CPU implementation with a **domain-decomposed parallel version**.
    -   **MPI**: Used for 1D domain decomposition along the Z-axis. Each MPI rank manages a slice of the 3D grid. `MPI_Sendrecv` handles halo exchanges (ghost cells) for neighbor communication.
    -   **CUDA**: Offloaded all compute-intensive tasks to the GPU:
        -   `initializeConcentration` (partial, with host-side setup for random consistency)
        -   `computeChemicalPotentialKernel`: Computes chemical potential using neighbor data.
        -   `cahnHilliardUpdateKernel`: Updates concentration field.
        -   `fillHalosKernel`: Handles boundary conditions on the device.
        -   Explicit device memory management and `cudaMemcpy` for data transfer.
    -   **OpenMP**:
        -   Used for parallel initialization of the concentration field on the host to speed up setup.
        -   Used for parallel validation of results on the host (gathering to rank 0 and reducing using OpenMP `reduction`).

### Parallel Strategy
-   **Decomposition**: The 3D grid is split along the Z dimension. This allows contiguous memory access for Z-slices, simplifying halo exchanges.
-   **Communication**: Halo regions (top and bottom slices) are exchanged between neighboring MPI ranks at each time step for both concentration (`c`) and chemical potential (`mu`).
-   **Computation**: Kernels operate on local subgrids on the GPU. Global boundary conditions (clamped) are enforced by kernels/halo logic.

### Results
-   **Correctness**: Validated against the original serial version. The output concentration range matches the baseline (e.g., `[-0.864946, 0.878023]`).
-   **Performance**: Achieved significant speedup (e.g., ~655 MCellUpdates/s on 2 ranks vs ~238 MCellUpdates/s serial) on the test environment. Scalability on a cluster is ensured by the MPI design.

The executable name remains `cahn_hilliard`. No new files were created in the repository structure.
