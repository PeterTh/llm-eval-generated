HYBRID MPI+OpenMP+CUDA MATRIX MULTIPLICATION IMPLEMENTATION
============================================================

PARALLELIZATION STRATEGY:
-------------------------
1. MPI (Message Passing Interface):
   - Distributes matrix rows across multiple processes
   - Each MPI process handles a portion of the output matrix C
   - Uses MPI_Allgatherv to gather results from all processes

2. OpenMP (Open Multi-Processing):
   - Used for parallel matrix initialization
   - #pragma omp parallel for collapse(2) parallelizes nested loops
   - Each MPI process uses multiple CPU threads for initialization

3. CUDA (Compute Unified Device Architecture):
   - GPU acceleration for the actual matrix multiplication
   - Each MPI process uses its assigned GPU (via rank % num_gpus)
   - 16x16 thread blocks for optimal GPU utilization
   - Kernel performs element-wise computation in parallel

IMPLEMENTATION DETAILS:

BUILD REQUIREMENTS:
------------------
- CMake 3.18+

EXECUTION:
----------
mpirun -np <num_processes> ./matmul [options]
  -n <size>  : Matrix dimension (default: 512)
  -v         : Enable validation
  -r         : Print results for external validation
  -h         : Show help
