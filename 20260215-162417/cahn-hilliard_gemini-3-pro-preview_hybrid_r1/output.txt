The Cahn-Hilliard benchmark code has been parallelized using a hybrid approach with MPI, OpenMP, and CUDA.

The `CMakeLists.txt` file was updated to enable CUDA and find MPI and OpenMP packages. The `cahn_hilliard.cpp` file was completely rewritten to incorporate the following parallelization strategies:

1.  **MPI Domain Decomposition**: The 3D grid is decomposed along the Z-axis. Each MPI rank handles a sub-domain of size `nx * ny * local_nz`, with ghost layers (halo regions) at the top and bottom boundaries for communication with neighboring ranks.
2.  **CUDA Acceleration**: The core computational kernels (`computeChemicalPotential` and `cahnHilliardUpdate`) and the helper function `computeLaplacian` were ported to CUDA device kernels. Data resides on the GPU for the duration of the simulation to minimize host-device transfer overhead.
3.  **OpenMP Parallelism**: OpenMP is used on the host side for the parallel initialization of the concentration field before copying it to the GPU.
4.  **Halo Exchange**: Explicit halo exchange routines were implemented using `cudaMemcpy` (Device-to-Host and Host-to-Device) and `MPI_Isend`/`MPI_Irecv` to synchronize the ghost layers between iterations.
5.  **Verification**: The result gathering and verification logic was updated to collect data from all ranks to rank 0 for validation and output.

The resulting program will automatically use all available resources: MPI for distributed memory scaling, OpenMP for multi-core host operations, and CUDA for massive parallelism on GPUs. No new external dependencies were introduced beyond the required MPI, OpenMP, and CUDA libraries.
