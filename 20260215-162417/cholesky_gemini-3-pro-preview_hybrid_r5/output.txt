    *   **MPI (Distributed Memory):** Implemented a 1D Block Row Cyclic distribution (simplified to Block Row for benchmarking simplicity but ensuring scalability).         *   Optimized GEMM calls by batching updates for all local blocks in the trailing submatrix into a single kernel call per column block, significantly improving performance.
    *   **OpenMP (Shared Memory):** Used for parallelizing the validation logic and the fallback matrix generation routine.
    *   **Optimization:** Replaced the slow sequential matrix generation ($O(N^3)$) with a fast cuBLAS-based generation (or OpenMP fallback), allowing for rapid benchmarking of large matrices (e.g., 4096+).
