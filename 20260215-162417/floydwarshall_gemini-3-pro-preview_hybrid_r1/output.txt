I have parallelized the Floyd-Warshall benchmark using a hybrid MPI + OpenMP + CUDA approach.

The solution includes:
1.  **MPI** for inter-node communication:
    *   The distance and path matrices are distributed row-wise across MPI processes.
    *   `MPI_Scatterv` distributes the initial data.
    *   In each iteration $k$, the process owning row $k$ broadcasts it to all other processes using `MPI_Bcast`.
    *   `MPI_Gatherv` collects the final results to the root process.
2.  **CUDA** for massive parallelism:
    *   The core update loop is offloaded to the GPU.
    *   Each MPI process maintains its local chunk of the matrix in GPU memory.
    *   A custom CUDA kernel `floyd_kernel` computes the updates for the local rows.
    *   Data transfer between Host and Device is minimized; only the broadcasted row $k$ is transferred to the device in each iteration.
3.  **OpenMP** for host-side parallelism:
    *   Used for parallel validation of the results on the host (checking diagonal zeros and triangle inequality).
    *   Enabled in the build system to work alongside CUDA.
