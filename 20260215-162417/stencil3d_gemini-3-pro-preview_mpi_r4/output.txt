**Key Changes:**

1.  **Domain Decomposition:** The 3D grid is divided into slabs along the Z-axis. Each MPI rank processes a subset of the Z layers (`local_nz`), plus two ghost layers (top and bottom) for halo exchange.
2.  **Halo Exchange:** Implemented `exchangeHalos` function using `MPI_Sendrecv` to swap boundary layers between neighboring ranks before each iteration.
3.  **Initialization:** Modified `initializeGrid` to correctly initialize the local portion of the grid using global coordinates, ensuring the same initial state as the serial version.
4.  **Result Gathering:** Implemented `gather_grid` using `MPI_Gatherv` to collect the distributed grid back to rank 0 for validation and result printing. This ensures that the output format and validation logic remain identical to the original code.
5.  **Build System:** Updated `CMakeLists.txt` to find and link the MPI library.

**Verification:**
The parallel implementation was verified with 1, 2, and 4 MPI ranks. The results (numerical values, checksums, and validation logic) are identical to the serial execution. Performance scaling was observed (e.g., ~3.5x speedup with 4 ranks).
