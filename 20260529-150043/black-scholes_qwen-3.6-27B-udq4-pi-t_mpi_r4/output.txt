The Black-Scholes benchmark has been parallelized with MPI. Here's a summary of the changes:

## Changes Made

### `black_scholes.cpp`
- **Added `#include <mpi.h>`** — MPI initialization and communication
- **Modified `generateOptions()`** — Takes an `offset` parameter so each rank generates only its local portion of options (deterministic based on global index)
- **Replaced `std::chrono` timing with `MPI_Wtime()`** — Consistent wall-clock timing across ranks, with `MPI_Barrier` synchronization before/after computation
- **Block distribution** — Options are distributed as contiguous blocks across ranks: rank `r` gets `N/P + (r < N%P)` options starting at offset `r * N/P + min(r, N%P)`
- **`MPI_Gatherv`** — Gathers local results to rank 0 for unified output/validation
- **Rank-0-only output** — All `printf` calls for info/results/validation are guarded by `rank == 0`

### `CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Added `target_include_directories` for MPI headers
- Added `${MPI_CXX_LIBRARIES}` to link dependencies

## Correctness Verification
- **Bit-identical results** across 1, 2, 3, 4, 5, 7, and 8 processes (verified via hash)
- **Handles uneven splits** correctly (e.g., 13 options across 3 processes)
- **Validation passes** in all configurations
