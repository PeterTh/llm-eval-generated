## Changes Made

### `roomsim/roomsim.cpp` - Full MPI parallelization
- **MPI initialization**: `MPI_Init`/`MPI_Finalize` in main, rank-aware output
- **Block distribution**: Triangles distributed evenly across MPI ranks using floor-based block distribution
- **Form Factors (Kij)**: Each rank computes its owned rows; RNG values pre-distributed via `MPI_Scatterv` from rank 0 for deterministic results; results gathered via `MPI_Allgatherv`
- **Time Delays (Tau)**: Each rank computes owned rows; results gathered via `MPI_Allgatherv`
- **Simulation**: Each rank computes its owned triangles per timestep; `MPI_Allgather` synchronizes radB values after each timestep
- **Distance Computation**: Each rank computes owned triangles; results gathered via `MPI_Allgatherv`
- **RNG determinism**: All RNG values generated on rank 0, then scattered to ranks. Each `(i,j)` pair consumes exactly 32 random numbers, so offset calculation is straightforward

### `roomsim/CMakeLists.txt` - MPI support
- Added `find_package(MPI REQUIRED)`
- Linked `${MPI_CXX_LIBRARIES}` and included `${MPI_CXX_INCLUDE_PATH}`
