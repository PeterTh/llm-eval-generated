Done. Here's a summary of the OpenMP parallelization:

### Changes to `stencil3d.cpp`

1. **Added `#include <omp.h>`** for OpenMP support.

2. **`initializeGrid`** — parallelized with `#pragma omp parallel for collapse(3) schedule(static)`. Each grid cell is independent.

3. **`stencilIteration`** — two parallel regions:
   - **Interior stencil computation** — `#pragma omp parallel for collapse(3) schedule(static)`. Each thread writes to a unique output index while reading from the shared (read-only) input array — no races.
   - **Boundary copy** — `#pragma omp parallel for collapse(3) schedule(static)`. Each boundary cell is written to exactly once.

4. **`validateResult`** — two parallel regions:
   - **NaN/Inf check** — uses `reduction(+:hasBadValue)` to count bad values across threads (replaced the original `break` which is illegal in OpenMP loops).
   - **Min/max computation** — uses `reduction(min:minVal)` and `reduction(max:maxVal)`.

### Changes to `CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)`
- Linked `OpenMP::OpenMP_CXX` to the target

### Verification

- **Correctness**: Validation passes, and results are bitwise identical (same hash) between 1-thread and multi-thread runs.
- **Speedup**: On a 256³ grid, ~4.4x speedup from 1 thread to all cores (121 → 534 MCellUpdates/s).
