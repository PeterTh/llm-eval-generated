Done. Here's a summary of the changes:

### `black-scholes/black_scholes.cpp`
- Replaced the sequential CPU `blackScholes()` function with a **CUDA kernel** (`blackScholesKernel`) that runs one thread per option
- Added `deviceNormalCDF()` using CUDA's `erfc()` for the normal CDF computation on GPU
- GPU workflow: allocate device memory → copy inputs → launch kernel → synchronize → copy results back → free memory
- Added CUDA error checking helper (`checkCuda`)
- Added GPU device info printing
- Includes a warm-up kernel launch before timed execution for accurate benchmarking
- Uses 256 threads per block with grid size auto-calculated from `numOptions`

### `black-scholes/CMakeLists.txt`
- Added `find_package(CUDAToolkit REQUIRED)` to locate CUDA
- Enabled CUDA language with `enable_language(CUDA)`
- Set source file to compile with NVCC via `set_source_files_properties(... PROPERTIES LANGUAGE CUDA)`
- Configured CUDA architectures: `60;70;75;80;86` (Pascal through Ampere)

### Performance
- ~250M options/sec for 10K options (0.04 ms)
- ~654M options/sec for 1M options (1.5 ms)
- Results are numerically equivalent to the CPU reference (differences only in last few ULPs)
