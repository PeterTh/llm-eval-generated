## Changes Made

### `cholesky.cpp` - Full CUDA parallelization

**CUDA kernels added:**
- `generateRandomKernel` - LCG-based random number generation on GPU
- `addDiagonalKernel` - Adds diagonal dominance on GPU
- `transposeKernel` - Column-major ↔ row-major transpose using 2D thread blocks
- `zeroUpperTriangleKernel` - Zeros upper triangle in row-major storage

**`generatePositiveDefiniteMatrix`** - Now runs entirely on GPU:
1. Generates random matrix B via CUDA kernel
2. Computes A = B × B^T using cuBLAS `dgemm`
3. Adds diagonal dominance via CUDA kernel
4. Transposes result to row-major and copies to host

**`choleskyDecomposition`** - Now uses cuSOLVER on GPU:
1. Copies row-major A to GPU and transposes to column-major
2. Queries workspace size via `cusolverDnDpotrf_bufferSize`
3. Runs Cholesky factorization via `cusolverDnDpotrf`
4. Transposes result back to row-major, zeros upper triangle
5. Copies result to host

**`validateCholesky`** - Kept on CPU (not performance-critical)

### `CMakeLists.txt` - CUDA build configuration
- Enabled CUDA language with nvcc compilation
- Set architecture to sm_86 (RTX 3090)
- Linked cuBLAS and cuSOLVER via CUDAToolkit
