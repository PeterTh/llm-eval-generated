## Changes Made

### `unstructured/unstructured.cpp`

**CUDA Kernels added (9 total):**
1. **`buildConnectivityKernel`** - Parallel mesh connectivity construction (one thread per element)
2. **`setCornerMaterialsKernel`** - Sets inflow/outflow corner materials
3. **`initDynamicKernel`** - Parallel initialization of dynamic element state
4. **`simulationStepKernel`** - Core simulation step: each thread computes flux from neighbors and updates element energy (one thread per element)
5. **`energySumKernel`** - Parallel reduction for energy sum using shared memory
6. **`fluxSumKernel`** - Parallel reduction for flux sum using shared memory
7. **`energyMinMaxKernel`** - Parallel reduction for energy min/max using shared memory
8. **`hashKernel`** - Parallel hash computation with XOR reduction using shared memory

**Key optimizations:**
- **Device-side double buffering**: Pointer swap on device (zero-copy) between iterations
- **Shared memory reductions**: Block-level parallel reductions with coalesced memory access
- **256 threads/block**: Standard CUDA configuration for good occupancy
