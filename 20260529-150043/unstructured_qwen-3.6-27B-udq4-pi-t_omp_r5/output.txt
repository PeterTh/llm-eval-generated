### Changes made

**`unstructured.cpp`** — 5 parallelization points:

1. **`#include <omp.h>`** — Added OpenMP header
2. **`buildSquare2D` — element initialization loop**: `#pragma omp parallel for schedule(static)` — parallelizes the bulk zeroing of element arrays
3. **`buildSquare2D` — connectivity building loop**: `#pragma omp parallel for collapse(2) schedule(static)` — parallelizes the 2D grid traversal for building neighbor connections
4. **`runSimulation` — element update loop**: `#pragma omp parallel for schedule(static)` — the main hot loop; each element reads from `elements_dynamic` (read-only) and writes to `elements_dynamic_swap`, making it embarrassingly parallel with no data races
5. **`validateResults` — reduction loop**: `#pragma omp parallel for reduction(+:energy_sum,flux_sum) reduction(max:energy_max) reduction(min:energy_min) schedule(static)` — parallel reductions for sum/max/min
6. **`computeHash` — hash computation**: `#pragma omp parallel for reduction(^:hash) schedule(static)` — XOR-based parallel reduction (XOR is associative and commutative, so the hash is deterministic regardless of thread count)
