Done. Here's a summary of the MPI parallelization:

**CMakeLists.txt changes:**
- Added `find_package(MPI REQUIRED)` to locate MPI
- Changed `target_link_libraries` to link `MPI::MPI_CXX` instead of just `m`

**spmv.cpp changes:**
- Added `#include <mpi.h>`
- **MPI initialization**: `MPI_Init`/`MPI_Finalize` wrapping the entire program
- **Row-wise block distribution**: Matrix rows are distributed across ranks using a block scheme with remainder handling for non-evenly-divisible sizes
- **Data distribution**:
  - Rank 0 initializes the full CSR matrix and input vector
  - `MPI_Bcast` broadcasts the input vector (needed by all ranks for SpMV)
  - `MPI_Scatterv` distributes the matrix data (row delimiters, values, column indices) to each rank
  - Local row delimiters are offset to index into each rank's local val/cols arrays
- **Parallel SpMV**: Each rank independently computes its local rows via `spmvCpuLocal`
- **Result collection**: `MPI_Gatherv` assembles the output vector on rank 0
- **Timing**: Uses `MPI_Wtime` with `MPI_Barrier` synchronization for consistent wall-clock timing across all ranks
- **Validation**: Reference solution computed on rank 0; gathered results validated against it

**Test results** confirm correctness (identical hashes across rank counts) and scalability (GFLOPS increase with more ranks):
- 1 rank: ~1.6 GFLOPS (1024×1024)
- 2 ranks: ~3.2 GFLOPS (1024×1024) 
- 4 ranks: ~5.4 GFLOPS (4096×4096)
- 8 ranks: ~11.6 GFLOPS (16384×16384)
