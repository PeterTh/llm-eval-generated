## Summary

### Parallelization Strategy
- **MPI**: Distributes matrix rows across MPI ranks. Each rank gets a contiguous range of rows with corresponding non-zeros via `MPI_Scatterv`. The full vector is broadcast to all ranks via `MPI_Bcast` since each rank needs it for SpMV.
- **CUDA**: Uses NVIDIA's cuSPARSE library (`cusparseSpMV`) for optimized SpMV computation on each rank's assigned GPU. Memory and descriptors are pre-allocated and reused across iterations.
- **OpenMP**: Parallelizes CPU-side reference computation and data initialization.

### Key Implementation Details
1. **Row Distribution**: Matrix rows are partitioned evenly across ranks. Each rank's local CSR format is derived from the global format with appropriate offsets.
2. **cuSPARSE v2 API**: Uses the modern cuSPARSE API with sparse matrix and dense vector descriptors for optimal performance.
3. **GPU Context**: Pre-allocates device memory and cuSPARSE descriptors once, reusing them across all iterations to avoid allocation overhead.
4. **GPU Assignment**: Ranks are assigned to GPUs in round-robin fashion for multi-GPU nodes.

### Performance
- 4 ranks on 32768×32768 matrix: **536 GFLOPS**
- 3 ranks on 32768×32768 matrix: **358 GFLOPS**
- Results are numerically consistent across different rank counts (same sums, samples, within tolerance).
