The CUDA-parallelized Floyd-Warshall implementation is complete and working. Here's a summary of the changes:

## Changes Made

### `floydwarshall/floydwarshall.cpp`
- **Added CUDA runtime** (`#include <cuda_runtime.h>`) and marked `idx2` as `__host__ __device__`
- **GPU initialization kernels**: `initDistanceKernel`, `zeroDiagonalKernel`, `initPathKernel` - parallelize the O(N²) initialization across GPU threads
- **Floyd-Warshall kernel**: `floydWarshallKernel` - the core parallelization:
  - Outer `k` loop remains sequential (algorithmically required)
  - Inner `(i, j)` loops fully parallelized across a 2D grid of thread blocks
  - **Shared memory optimization**: Each block cooperatively loads the k-th row and k-th column into shared memory, reducing global memory traffic from O(N²) to O(N) per block per k-iteration
  - Grid-stride loop in shared memory load handles cases where N > threads_per_block
- **Memory management**: Device memory allocation/copy for dist and path matrices
- **Preserved**: All original semantics, CLI interface, validation logic, and output format

### `floydwarshall/CMakeLists.txt`
- Enabled CUDA language with `enable_language(CUDA)`
- Set C++17 standard for CUDA 12.0 compatibility
- Configured `sm_86` architecture for RTX 3090
- Added `../common` include directory
- Forced CUDA compilation for `.cpp` source
