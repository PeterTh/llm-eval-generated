The MPI parallelization is complete. Here's a summary of the changes:

## Changes Made

### `qtclustering/qtclustering.cpp`
- Added `#include <mpi.h>` for MPI support
- Added `qtClusteringMPI()` function that parallelizes the expensive candidate cluster generation phase:
  - **Data distribution**: All ranks share the full point dataset (broadcast from rank 0)
  - **Seed distribution**: In each clustering iteration, unclustered seed candidates are distributed across ranks using a simple range-based partitioning: `start_idx = (total_seeds * rank) / num_ranks`
  - **Parallel candidate evaluation**: Each rank independently generates candidate clusters for its assigned seeds
  - **Global best selection**: Uses `MPI_Allreduce` with `MPI_MAX` on a packed key `(cardinality << 32) | (~seed)` to find the globally best cluster (max cardinality, lowest seed index for ties) — preserving exact sequential semantics
  - **Broadcast**: The winning cluster's members are broadcast from the source rank using `MPI_Bcast`
- Modified `main()` to:
  - Initialize/finalize MPI
  - Parse arguments on rank 0, broadcast to all ranks
  - Generate data on rank 0, broadcast to all ranks
  - Run the parallel clustering
  - Print output on rank 0 only

### `qtclustering/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)`
- Linked `MPI::MPI_CXX` library
- Added `MPI_CXX_INCLUDE_PATH` to include directories
