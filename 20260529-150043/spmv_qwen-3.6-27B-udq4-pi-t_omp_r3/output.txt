### `spmv/spmv.cpp` — OpenMP parallelization

1. **Added `#include <omp.h>`** for OpenMP support.

2. **`fill()`** — Parallelized with `#pragma omp parallel for schedule(static)`. Uses thread-local `rand_r()` to avoid data races on the global `rand()` state.

3. **`spmvCpu()`** — The main SpMV kernel is parallelized at two levels:
   - **Outer loop** (over rows): `#pragma omp parallel for schedule(static)` — each row writes to a unique `out[i]`, so this is embarrassingly parallel with no race conditions. `static` scheduling gives good load distribution.
   - **Inner loop** (dot product per row): `#pragma omp simd reduction(+:t)` — enables SIMD vectorization of the dot product with proper reduction semantics.

4. **`verifyResults()`** — Parallelized with `#pragma omp parallel for schedule(static) reduction(min:failed)`. Uses a `reduction(min:failed)` to propagate failure across threads, with `#pragma omp critical` around `printf` calls to avoid interleaved output.

5. **`initRandomMatrix()`** — Left serial because it has inherently sequential dependencies (the `nnzAssigned` counter and `fillRemaining` flag). This is initialization code, not the benchmark hot path.

### `spmv/CMakeLists.txt` — OpenMP build support

- Added `find_package(OpenMP REQUIRED)` 
- Added `${OpenMP_CXX_FLAGS}` to compile options
- Added `${OpenMP_CXX_LIBRARIES}` to link libraries
