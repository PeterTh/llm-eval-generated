Done. Here's a summary of the OpenMP parallelization:

### Changes to `spmv/spmv.cpp`

1. **`#include <omp.h>`** — Added OpenMP header.

2. **`fill()`** — Parallelized with `#pragma omp parallel for schedule(static)`. Uses thread-local seeds via `rand_r()` to avoid the thread-safety issue of `rand()`.

3. **`spmvCpu()`** — Parallelized with `#pragma omp parallel for schedule(dynamic)`. This is the main kernel. Each row is independent, so the outer loop is trivially parallel. Dynamic scheduling handles load imbalance from varying row lengths in sparse matrices.

4. **`verifyResults()`** — Parallelized with `#pragma omp parallel for schedule(static) reduction(||:failed)`. Uses a shared `failed` flag with `reduction(||)` for early termination semantics, and `#pragma omp critical` for thread-safe printf output.

5. **`initRandomMatrix()`** — Left sequential (inherently sequential due to running `nnzAssigned` counter, and it's initialization-only, not in the benchmark loop).

### Changes to `spmv/CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)`
