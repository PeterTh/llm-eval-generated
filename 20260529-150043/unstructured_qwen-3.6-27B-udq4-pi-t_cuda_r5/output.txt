The CUDA parallelization is complete. Here's a summary of the changes:

### Changes Made

**`unstructured.cpp`** - Full CUDA GPU parallelization:
- Added `#include <cuda_runtime.h>`
- Added `DeviceWorld` struct for GPU device pointers and CUDA resources (stream, events)
- Created `simulationKernel` - a CUDA kernel where each thread processes one mesh element:
  - Uses `__restrict__` pointers for compiler alias analysis optimization
  - Computes energy flux from external flow and all connected neighbors
  - Writes to double-buffered swap array to avoid race conditions
- `runSimulation()` now:
  - Allocates GPU memory for all data structures
  - Uploads data to GPU
  - Sets L1 cache preference (`cudaFuncCachePreferL1`) for random neighbor access patterns
  - Uses CUDA stream for kernel launches
  - Uses CUDA events for accurate GPU-only timing (excludes data transfer overhead)
  - Double-buffer swap via pointer swap between iterations
  - Downloads results back to host
- Added `freeDeviceWorld()` for proper GPU resource cleanup
- Fixed integer overflow in GFLOPS calculation for large grids (uses `double` cast)
- Added GPU device info display
- Added error handling for missing CUDA device

**`CMakeLists.txt`** - Updated for CUDA compilation:
- Enabled CUDA language via `enable_language(CUDA)`
- Set CUDA standard to C++17
- Set CUDA architecture to 86 (Ampere, matches RTX 3090)
- Configured host compiler and optimization flags
- Set source file language to CUDA
