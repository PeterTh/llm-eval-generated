### `cholesky/cholesky.cpp`
Replaced the sequential Cholesky decomposition with a GPU-accelerated version:

**CUDA Kernels:**
1. **`transposeKernel`** - Parallel matrix transpose (row-major ↔ column-major) using 1D thread indexing with 256-thread blocks
2. **`zeroUpperKernel`** - GPU kernel to zero out the upper triangular part of the result matrix

**Core Algorithm (`choleskyDecomposition`):**
1. Copy symmetric matrix from host to device (row-major = column-major for symmetric matrices)
2. Call `cusolverDnDpotrf` for blocked Cholesky factorization on GPU
3. Transpose the result from column-major (cuSOLVER output) to row-major
4. Zero upper triangular part on GPU
5. Copy result back to host

**Key Design Decisions:**
- Uses **cuSOLVER's `cusolverDnDpotrf`** for highly optimized blocked Cholesky factorization
- Exploits that symmetric matrices have identical row-major/column-major byte layouts for input
- Transposes the non-symmetric output L back to row-major format
- Zeroes upper triangle on GPU to avoid CPU overhead
