The CUDA parallelization is complete. Here's a summary of the changes:

## Changes Made

### `stencil3d/stencil3d.cpp`
Rewrote the sequential stencil code with three optimized CUDA kernels:

1. **`initKernel`** - 3D-threaded grid initialization on GPU
2. **`stencilKernel`** - 7-point stencil with **shared memory tiling** (32×8×4 tile + 1-cell halo). Each thread loads its cell plus halo neighbors into shared memory, achieving fully coalesced global memory access in the x-dimension. After `__syncthreads()`, all 7 stencil reads come from fast shared memory.
3. **`copyBoundaryKernel`** - 1D grid-stride loop for boundary value copying

**Key optimizations:**
- Shared memory tiling reduces global memory reads from 7/thread to ~1/thread
- Warp-aligned x-dimension access for full coalescing
- GPU double-buffering avoids host transfers between iterations
- Handles arbitrary grid sizes (non-tile-aligned dimensions work correctly)

### `stencil3d/CMakeLists.txt`
- Added `enable_language(CUDA)` 
- Set `CMAKE_CUDA_ARCHITECTURES 80` (Turing, compatible with RTX 3090)
- Used `set_source_files_properties` to compile `.cpp` with nvcc
- Added `-O3` and `-Xptxas -O3` optimization flags
