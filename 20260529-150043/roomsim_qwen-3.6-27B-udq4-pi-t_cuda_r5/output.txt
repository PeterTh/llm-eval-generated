## Changes Made

### roomsim.cpp (885 lines)
Complete CUDA parallelization with:

**GPU Kernels:**
- `computeTauKernel` - O(N²) time delay computation using 2D thread grid
- `computeKijKernel` - O(N²) form factor computation with grid-based visibility testing
- `simulateStepKernel` - O(N) per-timestep wave propagation simulation
- `computeDistanceKernel` - O(N) cross-correlation distance estimation

**Key Optimizations:**
- **Grid-based spatial hash** instead of octree traversal - much faster on GPU with coalesced memory access and no stack allocation
- **3D DDA ray traversal** for efficient grid cell visitation during visibility testing
- **Per-thread visited set** to avoid duplicate triangle checks
- **2D grid launch** for O(N²) computations (tau, Kij)
- **1D grid launch** for O(N) computations (simulation, distance)
