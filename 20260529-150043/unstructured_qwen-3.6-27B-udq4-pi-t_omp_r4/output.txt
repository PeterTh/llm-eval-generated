## Changes Made

### `unstructured.cpp`
Added `#include <omp.h>` and parallelized four key regions:

1. **`buildSquare2D`** - Mesh connectivity building: `#pragma omp parallel for collapse(2) schedule(static)` — each element's neighbor computation is independent, so the nested x,y loops are parallelized with `collapse(2)`.

2. **`runSimulation`** - Core simulation loop: `#pragma omp parallel for schedule(static)` — each element reads from `elements_dynamic` (read-only during the phase) and writes to a unique index in `elements_dynamic_swap`, making this perfectly parallel. The outer iteration loop remains sequential due to data dependencies.

3. **`validateResults`** - Reduction operations: `#pragma omp parallel for reduction(+:...) reduction(max:...) reduction(min:...)` — sum, max, and min reductions are parallelized using OpenMP reduction clauses.

4. **`computeHash`** - Hash computation: `#pragma omp parallel for reduction(^:hash)` — XOR reduction is associative/commutative, enabling safe parallelization with a local hash accumulator per thread.

### `CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)`
- Added `OpenMP::OpenMP_CXX` to `target_link_libraries`
