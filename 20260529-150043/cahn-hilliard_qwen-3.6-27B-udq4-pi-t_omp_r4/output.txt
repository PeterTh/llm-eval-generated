Done. Here's a summary of the OpenMP parallelization:

### Changes to `cahn_hilliard.cpp`
1. **Added `#include <omp.h>`** for OpenMP support
2. **`computeChemicalPotential`** — Added `#pragma omp parallel for collapse(3) schedule(static)` to parallelize the triple-nested x/y/z loop. Each grid cell writes to a unique index in `mu[]`, and reads are all from the shared `c[]` array (read-only, no race).
3. **`cahnHilliardUpdate`** — Same `collapse(3)` parallelization. Each thread writes to a unique index in `cnew[]`, reading from `cold[]` and `mu[]` (both read-only).
4. **`initializeConcentration`** — Same `collapse(3)` parallelization. Each thread writes to a unique index in `c[]`.
5. **`validateResult`** — Parallelized the NaN/Inf check with `#pragma omp parallel for` (using a shared boolean flag), and the min/max reduction with `#pragma omp parallel for reduction(min:max)` for correctness.

### Changes to `CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)` 
- Added `OpenMP::OpenMP_CXX` to `target_link_libraries` (replacing the direct `m` link with `PRIVATE OpenMP::OpenMP_CXX m`)
