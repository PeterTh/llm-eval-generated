## Changes Made

### `spmv/spmv.cpp` — CUDA Parallelization

**New CUDA kernel (`spmvGpu`)**:
- Each thread processes one matrix row (1 thread = 1 row)
- Uses `__restrict__` pointers for compiler optimization hints
- Uses `__ldg()` intrinsic for read-only cached vector access, reducing global memory traffic
- Block size of 256 threads for good GPU occupancy

**GPU memory management**:
- Device memory allocation for all CSR data (`val`, `cols`, `rowDelimiters`), input vector, and output vector
- `cudaMemcpy` for host-to-device transfer before computation and device-to-host after
- Proper cleanup of all device resources

**Precise GPU timing**:
- CUDA streams for asynchronous execution
- CUDA events (`cudaEventRecord`/`cudaEventElapsedTime`) for accurate kernel timing that excludes data transfers
- Warmup run before timed iterations to ensure caches are populated

**Error handling**: `CUDA_CHECK` macro for all CUDA API calls

**Preserved**: All original semantics — `fill`, `initRandomMatrix`, `spmvCpu` (for validation), `verifyResults`, CLI interface, and output format remain unchanged.

### `spmv/CMakeLists.txt` — CUDA Build Support

- `enable_language(CUDA)` to activate CUDA compilation
- `set_source_files_properties(spmv.cpp PROPERTIES LANGUAGE CUDA)` to compile the `.cpp` file with `nvcc`
- CUDA standard set to C++17
- Default compute architecture 80 (Ampere), overridable via `CMAKE_CUDA_ARCHITECTURES`
- `-lineinfo` for CUDA profiling/debugging support
