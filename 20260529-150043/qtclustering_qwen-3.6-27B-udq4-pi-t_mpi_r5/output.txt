**MPI Initialization**: All ranks call `MPI_Init`/`MPI_Finalize`; only rank 0 handles output.

**Data Distribution**: 
- `generateSyntheticData` runs on rank 0 only, then `MPI_Bcast` distributes points to all ranks
- All ranks maintain full copies of `points[]` and `clustered[]` (needed for distance calculations)

**Parallel Clustering** (`qtClusteringMPI`):
- Each iteration partitions `unclustered_indices` across ranks via block distribution
- Each rank independently evaluates its local seeds (embarrassingly parallel)
- `MPI_Gather` collects local best candidates to rank 0
- Rank 0 selects the global best (highest cardinality, lowest seed on tie — matching sequential semantics)
- `MPI_Bcast` distributes the selection to all ranks
- Winner rank `MPI_Bcast` its cluster members to all ranks
- All ranks update `clustered[]` and `unclustered_indices` in lockstep
