### `matmul/matmul.cpp`
- Added `#include <algorithm>` (for `std::min`) and `#include <omp.h>`
- **`initMatrix`**: Parallelized with `#pragma omp parallel for collapse(2) schedule(static)` — each element is independent
- **`matrixMultiply`**: Replaced the naive triple-nested loop with a **3D-tiled, OpenMP-parallelized** implementation:
  - `collapse(2)` on the `ii,jj` tile loops distributes work across threads with `schedule(static)` for predictable load balancing
  - Each `(ii,jj)` tile is independent — no races possible
  - Inner `k` dimension is tiled (TILE=64) for cache reuse, with partial sums accumulated via `(kk == 0) ? 0.0 : C[iN + j]`
  - Pre-computed `iN = i * N` to avoid redundant multiplications in the inner loop

### Verification
- All sizes pass validation (100, 128, 256, 512, 1024), including non-tile-aligned dimensions
- Scales linearly with thread count (1→2→4→max threads shows proportional speedup)
