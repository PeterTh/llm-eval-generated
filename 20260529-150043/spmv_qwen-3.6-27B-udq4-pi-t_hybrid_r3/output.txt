## Summary

### Architecture
- **MPI**: Distributes matrix rows across MPI ranks using static block distribution. Each rank gets a contiguous range of rows. The full vector is broadcast to all ranks since any row can reference any column.
- **OpenMP**: Parallelizes the CPU-side data initialization and reference solution computation on rank 0.
- **CUDA**: Each MPI rank offloads its portion of the SpMV computation to its local GPU. The kernel uses 256 threads per block with shared memory reduction for efficient dot product computation.

### Key Design Decisions
1. **Data Distribution**: CSR matrix rows are partitioned across ranks. Rank 0 computes the distribution and sends data to other ranks via MPI point-to-point communication.
2. **GPU Kernel**: Each thread block handles one matrix row. Threads within a block cooperatively compute the dot product using a grid-stride loop, then perform a parallel reduction in shared memory.
3. **Timing**: Uses CUDA events for precise GPU timing that excludes host overhead.
4. **Correctness**: Results are gathered to rank 0 via `MPI_Gatherv` and validated against a CPU reference solution.
