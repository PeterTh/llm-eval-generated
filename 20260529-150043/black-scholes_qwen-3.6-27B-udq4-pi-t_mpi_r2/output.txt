## Changes Made

### `black_scholes.cpp`
- **Added `#include <mpi.h>`** for MPI support
- **`MPI_Init`/`MPI_Finalize`** wrapping the entire program lifecycle
- **Block-distributed work**: Options are split into contiguous chunks across ranks using a standard block distribution (`baseChunk + remainder handling`)
- **Local generation**: `generateOptions()` modified to accept `(start, count)` so each rank generates only its own portion independently — no broadcast needed
- **Local computation**: Each rank prices only its own options
- **`MPI_Barrier`** before timing to synchronize all ranks
- **`MPI_Gatherv`** to collect results and options back to rank 0 for validation/output
- **`MPI_Reduce`** (MPI_MAX) to report the makespan (slowest rank's timing)
- **Rank 0 I/O**: All printf output goes through rank 0 only

### `CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Added `target_include_directories` for MPI headers
- Added `${MPI_CXX_LIBRARIES}` to link libraries
