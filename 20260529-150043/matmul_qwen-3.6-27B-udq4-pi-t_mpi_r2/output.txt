## Changes Made

### `matmul/matmul.cpp`
- **MPI initialization**: Added `MPI_Init`/`MPI_Finalize` and rank/size queries
- **1D row-block distribution**: Matrix rows are distributed across processes using `MPI_Scatterv`/`MPI_Gatherv`. Each process computes its assigned row block of C.
- **Memory layout**: Each process stores only its rows of A and C, plus the full matrix B (broadcast via `MPI_Bcast`)
- **Cache-optimized kernel**: Reordered loops to `(i,k,j)` order for better cache utilization — streaming through B rows while accumulating into C
- **Collective communication**:
  - `MPI_Bcast` for parameters and matrix B
  - `MPI_Scatterv` to distribute matrix A by rows
  - `MPI_Gatherv` to collect result C back to rank 0
  - `MPI_Barrier` to synchronize timing across all processes
- **Rank-0 I/O**: Only rank 0 handles all output (printf, validation, results)

### `matmul/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Linked `${MPI_CXX_LIBRARIES}` and included `${MPI_CXX_INCLUDE_DIRS}`
