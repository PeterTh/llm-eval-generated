The Black-Scholes benchmark has been successfully parallelized with CUDA. Here's a summary of the changes:

## Changes Made

### `black-scholes/black_scholes.cpp`
- Added `#include <cuda_runtime.h>` for CUDA runtime API
- Replaced the CPU `blackScholes()` function with a `__device__` helper (`device_cdf`) using CUDA's built-in double-precision `erf()`
- Added a `__global__` CUDA kernel `blackScholesKernel` where each thread prices one option independently
- Replaced the sequential pricing loop in `main()` with:
  - `cudaMalloc` for device memory allocation
  - `cudaMemcpy` (H2D) to transfer option data to GPU
  - Kernel launch with 256 threads/block grid-stride pattern
  - `cudaDeviceSynchronize()` for accurate timing
  - `cudaMemcpy` (D2H) to transfer results back
  - `cudaFree` for cleanup
- Added `CUDA_CHECK` macro for error handling

### `black-scholes/CMakeLists.txt`
- Added `enable_language(CUDA)` and CUDA standard settings
- Added `set_source_files_properties(black_scholes.cpp PROPERTIES LANGUAGE CUDA)` to compile with nvcc
- Updated compile options to pass host flags via `-Xcompiler`
