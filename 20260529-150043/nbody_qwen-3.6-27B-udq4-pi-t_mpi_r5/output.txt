The MPI parallelization is complete and verified. Here's a summary:

## Changes Made

### `nbody/nbody.cpp`
- Added `#include <mpi.h>` and `MPI_Init`/`MPI_Finalize` lifecycle
- **Block distribution**: Bodies are evenly partitioned across MPI ranks using a block scheme (handles non-divisible counts)
- **Deterministic initialization**: Each rank advances `rand_r` to its offset, producing identical initial conditions regardless of rank count
- **`MPI_Allgatherv`**: Every step gathers body positions/velocities from all ranks so each rank has the full global state for O(N²) force computation
- **Parallel force computation**: Each rank computes forces only for its locally owned bodies (O(N²/P) per rank)
- **Parallel energy**: Each rank computes energy contributions for pairs where the first index is local, then `MPI_Reduce` with `MPI_SUM` aggregates
- **Parallel validation**: Each rank validates its local bodies, `MPI_Allreduce` with `MPI_MIN` checks global validity
- **Results printing**: Only rank 0 prints results (has full state via allgather)

### `nbody/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)`
- Linked `MPI::MPI_CXX` instead of just `m`
- Added `target_include_directories` for MPI headers

## Verification
- **Correctness**: Identical hash output across 1, 2, and 4 ranks for both divisible (256) and non-divisible (300) body counts
- **Scalability**: Near-linear speedup on 2048 bodies (1570ms → 787ms → 399ms for 1→2→4 ranks)
