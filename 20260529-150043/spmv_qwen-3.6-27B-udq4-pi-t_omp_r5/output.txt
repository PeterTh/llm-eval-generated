### Changes to `spmv/spmv.cpp`:

1. **Added `#include <omp.h>`** for OpenMP runtime support.

2. **`spmvCpu` (main kernel)** - Added `#pragma omp parallel for schedule(static)` to parallelize the outer row loop. Each row's dot product is independent, making this embarrassingly parallel. `static` scheduling is optimal since work per row is roughly uniform for random matrices.

3. **`fill`** - Added `#pragma omp parallel for schedule(static)` with a thread-local LCG (linear congruential generator) to replace the non-thread-safe `rand()` call. Each thread maintains its own seed via `thread_local` storage.

4. **`verifyResults`** - Parallelized the comparison loop with `#pragma omp parallel for schedule(static)` and used `#pragma omp critical` sections to safely capture the first validation failure across threads.

5. **Main function** - Added thread count display: `printf("Computing SpMV with %d OpenMP threads...")`.
