The hybrid parallelization is complete and working. Here's a summary of the changes:

## Changes Made

### `black_scholes.cpp`

**CUDA (GPU compute)**:
- Added `__device__` functions (`d_cumulativeNormal`, `d_normalPDF`, `d_blackScholes`) that mirror the host Black-Scholes implementation
- Added `__global__` kernel `blackScholesKernel` — one thread per option, 256 threads/block
- GPU path: `cudaMalloc` → `cudaMemcpy` H2D → kernel launch → `cudaDeviceSynchronize` → `cudaMemcpy` D2H → `cudaFree`
- CPU fallback path with OpenMP when no GPU is available

**MPI (distributed memory)**:
- `MPI_Init`/`MPI_Finalize` wrapping the entire program
- Work distribution: each rank computes `numOptions / numRanks` options (with remainder handling)
- `MPI_Gatherv` to collect results and option data back to rank 0
- `MPI_Barrier` for synchronized timing
- Round-robin GPU assignment across ranks (`rank % deviceCount`)

**OpenMP (shared memory)**:
- `#pragma omp parallel for` on option generation loop
- `#pragma omp parallel for` on CPU fallback pricing loop
- Leverages all CPU cores on each node

### `CMakeLists.txt`

- Added `enable_language(CUDA)` with CUDA 17 standard
- `find_package(MPI REQUIRED)` and `find_package(OpenMP REQUIRED)`
- Source compiled via nvcc (`set_source_files_properties` → `LANGUAGE CUDA`)
- Host flags passed via `-Xcompiler=` (OpenMP, `-O3`, `-march=native`)
- Links `MPI::MPI_CXX`, `OpenMP::OpenMP_CXX`, and `m`
