The CUDA parallelization is complete and working. Here's a summary of the changes:

## Changes Made

### `roomsim/roomsim.cpp` - Full CUDA rewrite

**CUDA Device Code (new):**
- **Device types**: `Vec3f`, `TriangleF` (aligned for GPU memory)
- **Device helper functions**: Vector ops (`vec_add`, `vec_sub`, `vec_cross`, etc.), `rayTriangleIntersect` (Möller-Trumbore), `cosPhi`, `randomPointInTriangle`, `isRayBlocked`
- **4 CUDA Kernels:**
  1. `computeFormFactorsKernel` - Parallel over all N×N triangle pairs, each thread computes Kij with curand RNG and brute-force visibility test
  2. `computeTimeDelaysKernel` - Parallel over all N×N pairs computing Tau (center-to-center distance)
  3. `simulationStepKernel` - Parallel over triangles for one timestep (timesteps remain sequential due to data dependency)
  4. `computeDistancesKernel` - Parallel over triangles for cross-correlation distance computation

**Host-side changes:**
- Mesh generation stays on CPU (sequential, small data)
- All computation phases now call CUDA kernels via `computeFormFactorsCUDA`, `computeTimeDelaysCUDA`, `runSimulationCUDA`, `computeDistancesCUDA`
- Proper CUDA memory management (malloc, memcpy, memset, free) with error checking

### `roomsim/CMakeLists.txt` - CUDA build support

- Enabled CUDA language alongside CXX
- Set CUDA standard to 17
- Forced `roomsim.cpp` to compile as CUDA via `set_source_files_properties`
- Added `-O3` and `-march=native` optimizations for CUDA

## Parallelization Strategy

| Phase | Original | CUDA | Parallelism |
|-------|----------|------|-------------|
| Form Factors | N×N sequential | N×N parallel threads | Full N² parallelism |
| Time Delays | N×N sequential | N×N parallel threads | Full N² parallelism |
| Simulation | T×N×N sequential | T sequential × N parallel | Per-timestep parallelism |
| Distances | N sequential | N parallel threads | Full N parallelism |
