## Changes Made

### `cholesky/cholesky.cpp`

1. **Added `#include <omp.h>`** for OpenMP support.

2. **`choleskyDecomposition()`** — Rewrote from row-oriented to **column-oriented** algorithm with OpenMP parallelization:
   - Column `j` diagonal element computed sequentially (depends on columns 0..j-1)
   - Column `j` off-diagonal elements (rows i > j) parallelized with `#pragma omp parallel for schedule(static)` — each row update is independent since they only read from completed columns
   - Upper-triangle zeroing parallelized with `#pragma omp parallel for schedule(static)`

3. **`generatePositiveDefiniteMatrix()`** — Parallelized all three phases:
   - Random matrix generation with thread-safe per-element seeds
   - Matrix multiplication A = B*B^T parallelized over output rows
   - Diagonal addition parallelized

4. **`validateCholesky()`** — Parallelized:
   - L*L^T reconstruction over output rows
   - Error computation with `reduction(max:maxError, relError)`

5. **`main()`** — Added thread count display via `omp_get_max_threads()`.

### `cholesky/CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)`
- Added `OpenMP::OpenMP_CXX` to `target_link_libraries`
