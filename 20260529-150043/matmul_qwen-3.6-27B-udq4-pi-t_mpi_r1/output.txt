The MPI parallelization is complete. Here's a summary of the changes:

## Changes Made

### `matmul/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` to find MPI libraries
- Changed `target_link_libraries` to link `MPI::MPI_CXX` instead of just `m`

### `matmul/matmul.cpp`
- Added `#include <mpi.h>`
- **MPI initialization**: `MPI_Init`/`MPI_Finalize` wrap the program, `MPI_Comm_rank`/`MPI_Comm_size` get process info
- **1D row-block distribution**: Matrix A is partitioned across ranks by rows using `MPI_Scatterv` (handles uneven N/ranks division)
- **Matrix B**: Initialized identically on all ranks (deterministic pseudo-random), enabling each rank to compute independently
- **Local computation**: Each rank computes only its assigned rows of C
- **Result gathering**: `MPI_Gatherv` collects partial C blocks back to rank 0
- **Synchronized timing**: `MPI_Barrier` before/after computation for consistent wall-clock measurement
- **Rank 0 output**: All printf output is gated on `rank == 0` to avoid duplicate output
