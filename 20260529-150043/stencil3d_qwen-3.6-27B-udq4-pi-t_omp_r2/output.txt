### Changes made

**`stencil3d.cpp`:**
- Added `#include <omp.h>`
- **`initializeGrid`**: `#pragma omp parallel for collapse(3) schedule(static)` — all 3 loops collapsed for maximum parallelism on simple index assignment
- **`stencilIteration` (interior stencil)**: `#pragma omp parallel for collapse(2) schedule(static)` on `(z, y)` — collapses outer two loops while keeping the inner `x` loop serial for optimal cache behavior on row-major memory layout
- **`stencilIteration` (boundary copy)**: `#pragma omp parallel for collapse(3) schedule(static)` — simple copy with condition, safe to fully collapse
- **`validateResult`**: 
  - NaN/Inf check: `#pragma omp parallel for reduction(||: hasInvalid)` — uses boolean OR reduction instead of early return (which violates OpenMP structured block rules)
  - Min/max: `#pragma omp parallel for reduction(min: minVal) reduction(max: maxVal)`

**`CMakeLists.txt`:**
- Added `find_package(OpenMP REQUIRED)`
- Linked `OpenMP::OpenMP_CXX` to the target
