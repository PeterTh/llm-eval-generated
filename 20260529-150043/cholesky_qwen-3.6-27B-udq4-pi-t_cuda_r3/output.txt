### `cholesky/cholesky.cpp`
Rewrote the sequential Cholesky benchmark to use CUDA GPU parallelism:

- **Matrix generation on GPU**: Custom CUDA kernel (`generateRandomMatrix`) generates random matrix B in parallel, then `cublasDgemm` computes A = B×Bᵀ efficiently, and `addDiagonal` kernel adds diagonal dominance for positive definiteness
- **Cholesky decomposition via cuSOLVER**: Uses `cusolverDnDpotrf` (workspace-query + decomposition) for GPU-parallel Cholesky factorization
- **Column-major handling**: GPU libraries use column-major; code transposes results back to row-major for output/validation
- **Upper triangle zeroing**: cuSOLVER only writes the lower triangle; upper triangle is explicitly zeroed to match original semantics
