## Changes Made

### `matmul/matmul.cpp` — Hybrid MPI + OpenMP + CUDA matmul

**CUDA (GPU compute):**
- Tiled `__global__` kernel with 32×32 shared memory tiles for coalesced memory access
- Each MPI rank computes its portion of C on its assigned GPU
- Full boundary checking for non-divisible matrix dimensions

**MPI (cross-node/GPU distribution):**
- 1D row-wise block distribution of output matrix C across MPI ranks
- `MPI_Scatterv` distributes rows of A to each rank
- `MPI_Bcast` sends full B to all ranks  
- `MPI_Gatherv` collects local C blocks back to root
- Handles uneven row distribution (N not divisible by numRanks)

**OpenMP (CPU parallelism):**
- `#pragma omp parallel for collapse(2)` for parallel matrix initialization

### `matmul/CMakeLists.txt` — Updated build system
- Enables CUDA language with `enable_language(CUDA)` and SM 8.6 target
- Marks `matmul.cpp` as CUDA source (`set_source_files_properties`)
- Links MPI, OpenMP (`gomp`), and math libraries
- Passes host compiler flags through nvcc's `-Xcompiler`
