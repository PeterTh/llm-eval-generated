Key MPI parallelization strategy — **row-wise distribution** of the CSR matrix:

1. **MPI initialization**: `MPI_Init`/`MPI_Finalize` wrap the program
2. **Data initialization on rank 0**: Matrix, values, and vector are created only on rank 0
3. **Row partitioning**: Rows are distributed as contiguous blocks across ranks (with remainder handling for non-divisible cases)
4. **Communication pattern**:
   - `MPI_Bcast` row delimiters → all ranks compute their local partition
   - `MPI_Scatterv` values and column indices → each rank gets its local CSR data
   - `MPI_Bcast` input vector → all ranks need the full vector (rows reference arbitrary columns)
   - `MPI_Gatherv` results → rank 0 collects the complete output
5. **Local computation**: Each rank runs `spmvCpu` on its local rows
6. **Timing**: Uses `MPI_Wtime()` with `MPI_Barrier` synchronization for accurate wall-clock timing
7. **Validation**: Rank 0 computes a reference solution and validates the gathered results
