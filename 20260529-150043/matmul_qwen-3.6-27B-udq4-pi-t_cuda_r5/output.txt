### `matmul/matmul.cpp` — CUDA-parallelized matmul kernel

**Key optimizations:**
- **Shared memory tiling**: Uses 32×32 tiles in shared memory to reduce global memory bandwidth pressure. Each thread block loads tiles from A and B into `__shared__` memory, then computes partial products.
- **Coalesced memory access**: Threads in a warp access consecutive memory locations when loading from A and B, ensuring efficient memory coalescing.
- **`__restrict__` pointers**: Hints to the compiler that pointers don't alias, enabling better optimization.
- **Grid-stride via tile iteration**: Handles arbitrary matrix sizes (not just multiples of tile size) with proper boundary checks.
- **CUDA error checking**: Macro-based error checking for all CUDA runtime calls.

**Kernel launch config:** 32×32 thread blocks (1024 threads/block) with grid dimensions computed from N.
