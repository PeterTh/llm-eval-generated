Done. Here's a summary of the OpenMP parallelization:

### Changes to `nbody.cpp`
Added `#include <omp.h>` and parallelized all key functions:

| Function | Parallelization Strategy |
|---|---|
| **`randomizeBodies()`** | `#pragma omp parallel for` with per-iteration thread-local seed (deterministic, reproducible) |
| **`computeForces()`** | `#pragma omp parallel for` on the outer loop — each thread computes forces for one body independently (writes only to `bodies[i]`, reads all `bodies[j]`) |
| **`integrateBodies()`** | `#pragma omp parallel for` — each body's position update is independent |
| **`computeTotalEnergy()`** | Kinetic: `reduction(+:energy)` on per-body loop. Potential: `reduction(+:energy)` on outer loop of pair interactions |
| **`validateSimulation()`** | `#pragma omp parallel for` with `#pragma omp critical` on printf/error flag writes |

### Changes to `CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)`
- Linked `OpenMP::OpenMP_CXX` to the target (provides `-fopenmp` at compile and link time)
- Added `CXX_EXTENSIONS OFF` for portability

### Verified correctness
All thread counts (1, 2, 4) produce **identical results** (same hash `d03f1720456d2d41`, same energy values, validation passes).

### Performance (2048 bodies, 10 steps)
- 1 thread: 206 ms
- 2 threads: 105 ms (~1.96x speedup)
- 4 threads: 58 ms (~3.55x speedup)
