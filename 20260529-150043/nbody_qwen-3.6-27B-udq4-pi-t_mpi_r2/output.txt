## Changes Made

### `nbody/nbody.cpp`
- Added `#include <mpi.h>` and full MPI initialization/finalization
- **Data distribution**: All ranks hold a full copy of all bodies (needed for O(N²) force computation)
- **Work partition**: Bodies are divided evenly across ranks; each rank computes forces and integration only for its local subset `[localStart, localEnd)`
- **Synchronization**: `MPI_Allgatherv` after each step to gather each rank's local updates into the complete body array on all ranks (1 communication per step)
- **Initialization**: `MPI_Bcast` from rank 0 to distribute initial body data
- **Validation**: Each rank validates its local bodies, then `MPI_Allreduce` (MIN) for global result; energy computed locally per rank then `MPI_Reduce` (SUM)
- **Output**: Only rank 0 prints to avoid duplicate output

## Parallelization Strategy
- **Replicated data, partitioned work**: Each rank has all N bodies but only computes forces/integration for N/P bodies
- **One Allgatherv per step**: Minimal communication overhead — just 1 collective per simulation step
- **Exact numerical equivalence**: Force iteration order is preserved per body, yielding identical results (verified by matching hashes) across 1, 2, 3, and 4 ranks
- **~4x speedup** on 4 ranks for 4096 bodies (2502ms → 633ms)
