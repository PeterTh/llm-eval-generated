The CUDA-parallelized Floyd-Warshall benchmark is complete. Here's a summary:

## Changes Made

### `floydwarshall.cpp`
- **CUDA kernel** (`floydWarshallKernel`): Tiled approach with shared memory. For each fixed intermediate node `k`, all `(i,j)` pairs are parallelized across GPU threads. Each block processes a 32×32 tile, loading the k-row and k-column into shared memory to reduce global memory reads.
- **Grid-stride loop**: 1D thread blocks (256 threads) with grid-stride loop for scalability across problem sizes.
- **Device memory management**: Explicit `cudaMalloc`/`cudaMemcpy` for host-to-device and device-to-host transfers.
- **Correctness**: Preserves the original column-major memory layout and FW relaxation semantics.

### `CMakeLists.txt`
- Added `enable_language(CUDA)` for CUDA support
- Set `CMAKE_CUDA_ARCHITECTURES 86` (Ampere/RTX 30xx)
- Configured the `.cpp` source to compile as CUDA via `set_source_files_properties`
