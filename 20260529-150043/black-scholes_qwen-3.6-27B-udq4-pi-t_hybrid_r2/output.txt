## Architecture: Hybrid MPI + OpenMP + CUDA

### MPI (Distributed Memory)
- Work is distributed across MPI ranks using contiguous chunk decomposition
- `MPI_Gatherv` collects partial results from all ranks to rank 0
- `MPI_Init_thread` with `MPI_THREAD_FUNNELED` for OpenMP compatibility

### CUDA (GPU Acceleration)
- **Custom CUDA kernel** `blackScholesKernel` prices all options in parallel across GPU threads
- **Device-side erf approximation** (Abramowitz & Stegun) avoids expensive host-device calls
- **Structure-of-Arrays (SoA)** layout for coalesced memory access on GPU
- Round-robin device assignment: each MPI rank gets a dedicated GPU
- CUDA events for precise timing (warm-up launch excluded)

### OpenMP (CPU Threads)
- `#pragma omp parallel for` parallelizes option data generation
- `#pragma omp parallel for` parallelizes SoA data splitting before GPU transfer
