The Floyd-Warshall benchmark has been successfully parallelized with CUDA. Here's a summary of the changes:

## Changes Made

### `floydwarshall.cpp`
- Added `#include <cuda_runtime.h>` for CUDA API
- Added a **CUDA kernel** (`floydWarshallKernel`) that:
  - Uses a 32×32 2D thread block layout
  - Uses **shared memory tiling** to cache the k-th row (`dist[k][j]`) and k-th column (`dist[i][k]`) for coalesced memory access
  - Each thread handles one `(i, j)` pair, computing the relaxation step
- Replaced the serial triple-nested loop in `floydWarshall()` with:
  - GPU memory allocation (`cudaMalloc`)
  - Host-to-device copy (`cudaMemcpy`)
  - Sequential k-loop (required by algorithm dependency) launching parallel kernels per iteration
  - Device-to-host copy back
  - GPU memory cleanup (`cudaFree`)
- All other functions (initialization, validation, main) remain unchanged for semantic equivalence

### `CMakeLists.txt`
- Added `enable_language(CUDA)` and CUDA standard settings
- Added GPU architecture auto-detection via `nvidia-smi` (falls back to sm_80)
- Set `CMAKE_CUDA_ARCHITECTURES` for proper compilation
- Marked the `.cpp` source file to compile with nvcc via `set_source_files_properties`
