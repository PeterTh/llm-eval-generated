The Cahn-Hilliard benchmark is now parallelized with OpenMP. Here's a summary of the changes:

## Changes Made

### `cahn-hilliard/cahn_hilliard.cpp`

1. **Added `#include <omp.h>`** for OpenMP support

2. **Parallelized `initializeConcentration`** with `#pragma omp parallel for collapse(3) schedule(static)` — each grid cell initializes independently

3. **Parallelized `computeChemicalPotential`** with `#pragma omp parallel for collapse(3) schedule(static)` — each cell's chemical potential depends only on read-only `c` values

4. **Parallelized `cahnHilliardUpdate`** with `#pragma omp parallel for collapse(3) schedule(static)` — each cell's update depends only on read-only `mu` and `cold` values

5. **Parallelized `validateResult`** with:
   - `#pragma omp parallel for reduction(||:invalid)` for NaN/Inf check
   - `#pragma omp parallel for reduction(min:minVal) reduction(max:maxVal)` for range check

6. **Added thread count display** via `omp_get_max_threads()`

### `cahn-hilliard/CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)`
- Linked `OpenMP::OpenMP_CXX` to the target

## Key Design Decisions

- **`collapse(3)`** on the triple-nested loops distributes work evenly across threads regardless of grid shape
- **`schedule(static)`** provides predictable load balancing since all iterations do equal work
- **Time-stepping loop is NOT parallelized** — each step depends on the previous iteration's results (sequential dependency preserved)
