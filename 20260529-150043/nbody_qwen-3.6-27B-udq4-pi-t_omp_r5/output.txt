### Changes to `nbody.cpp`

1. **Added `#include <omp.h>`** for OpenMP support.

2. **`randomizeBodies`** - Parallelized with `#pragma omp parallel for schedule(static)`. Each iteration uses a thread-local seed derived from the body index to avoid races on the RNG state.

3. **`computeForces`** - Parallelized the outer loop (`i`) with `#pragma omp parallel for schedule(static)`. Each thread independently computes forces for its assigned bodies — no race conditions since each iteration reads from all bodies and writes only to its own body's velocity.

4. **`integrateBodies`** - Parallelized with `#pragma omp parallel for schedule(static)`. Each body's position update is independent.

5. **`computeTotalEnergy`** - Parallelized both kinetic and potential energy loops with `#pragma omp parallel for reduction(+:energy) schedule(static)`. The `reduction` clause safely accumulates partial sums across threads.

6. **`validateSimulation`** - Parallelized with `#pragma omp parallel for schedule(static)`. Uses `#pragma omp critical` for printf calls and a shared `failed` flag.

### Changes to `CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)` 
- Changed `target_link_libraries` to link `OpenMP::OpenMP_CXX` (which provides both compile and link flags)
