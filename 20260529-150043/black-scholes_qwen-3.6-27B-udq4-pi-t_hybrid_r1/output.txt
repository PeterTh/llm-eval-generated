### `black_scholes.cpp`
**CUDA (GPU compute):**
- `blackScholesKernel` — each GPU thread prices one option independently using double-precision `erf()` for the cumulative normal distribution. Options are processed in parallel across 256-thread blocks.

**MPI (multi-node/rank distribution):**
- Options are distributed across MPI ranks via scatter from root
- Each rank processes its local chunk independently on its assigned GPU
- Results are gathered back to root via `MPI_Gatherv` for unified output
- GPU affinity: `deviceId = rank % deviceCount` for multi-GPU systems

**OpenMP (CPU-side parallelism):**
- `generateOptions()` uses `#pragma omp parallel for` for parallel data generation
- CPU fallback path uses OpenMP parallel loop when no GPU is available
