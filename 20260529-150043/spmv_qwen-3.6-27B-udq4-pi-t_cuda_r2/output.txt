The SpMV benchmark has been successfully parallelized with CUDA. Here's a summary of the changes:

## Changes to `spmv/spmv.cpp`

**New CUDA kernel (`spmvKernel`)**:
- Each thread block handles one matrix row (grid = `numRows` blocks)
- 256 threads per block compute partial dot-product contributions for their assigned row
- Tree-based reduction in `__shared__` memory combines partial sums into the final result per row
- `__restrict__` pointers for better compiler optimization
- `extern __shared__` for flexible shared memory sizing

**Main function changes**:
- CUDA device initialization and GPU name reporting
- Device memory allocation (`cudaMalloc`) for all CSR data and vectors
- Host-to-device data transfer (`cudaMemcpy`) before computation
- Warmup iteration to eliminate cold-start effects
- CUDA event-based timing (`cudaEventRecord`/`cudaEventElapsedTime`) for accurate GPU kernel timing
- Device-to-host result transfer after computation
- Proper cleanup of CUDA events and device memory

**Preserved**:
- `spmvCpu` kept as CPU reference for validation
- Same command-line interface and output format
- Same validation logic and error tolerance

## Changes to `spmv/CMakeLists.txt`

- Added `enable_language(CUDA)` with `CMAKE_CUDA_ARCHITECTURES 86` (RTX 3090)
- Set `CMAKE_CUDA_STANDARD 20`
- Marked `spmv.cpp` as CUDA source via `set_source_files_properties`
- Added `--expt-relaxed-constexpr` flag
