## Changes Made

### `roomsim/roomsim.cpp`
Added `#include <omp.h>` and parallelized all major compute phases:

1. **`computeTimeDelays`** — `#pragma omp parallel for collapse(2) schedule(static)` on the N×N pair loop. Fully independent work items.

2. **`computeFormFactors`** — `#pragma omp parallel for collapse(2) schedule(static)` with per-thread RNGs (seeded deterministically per thread using `omp_get_thread_num()`). Each (i,j) pair gets a fresh RNG instance, making results deterministic regardless of thread count.

3. **`runSimulation`** — `#pragma omp parallel for schedule(static)` on the per-triangle loop within each timestep. Safe because timestep `t` only reads from earlier timesteps, and each thread writes to a distinct triangle index.

4. **`computeDistances`** — `#pragma omp parallel for schedule(static)` on the per-triangle loop. Each triangle's cross-correlation is independent.

5. **`validateResults`** — Three parallel loops with reductions:
   - Distance statistics: `reduction(||:allNonNegative) reduction(min:minDist) reduction(max:maxDist) reduction(+:sumDist,nonZeroCount)`
   - Energy reception count: `reduction(+:receivedEnergy)`
   - Non-zero Kij count: `reduction(+:nonZeroKij)`

6. **`computeHash`** — `#pragma omp parallel for reduction(^:hash)` using XOR reduction (associative and commutative).

### `roomsim/CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)`
- Changed link libraries to `OpenMP::OpenMP_CXX m`
