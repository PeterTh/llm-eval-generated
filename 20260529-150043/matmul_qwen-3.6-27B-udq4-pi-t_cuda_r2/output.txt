The CUDA-parallelized matmul benchmark is complete. Here's a summary of the changes:

### `matmul/matmul.cpp`
- Added `#include <cuda_runtime.h>` for CUDA API
- Replaced the serial `matrixMultiply` function with an optimized CUDA kernel:
  - **Tiled shared-memory kernel** (`matmulKernel`) with configurable `TILE_SIZE` (32x32)
  - **Coalesced memory access** for A matrix loads
  - **Boundary checks** for non-tile-aligned matrix sizes
  - **`__restrict__` pointers** for compiler optimization hints
- The `matrixMultiply` host function handles:
  - Device memory allocation (`cudaMalloc`)
  - Host-to-device transfer (`cudaMemcpy`)
  - Kernel launch with proper grid/block dimensions
  - Device-to-host transfer of results
  - Cleanup (`cudaFree`)
- All other functions (init, validation, CLI) preserved unchanged
