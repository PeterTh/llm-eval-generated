## Solution Summary

### Hybrid MPI + CUDA + OpenMP Parallelization

**MPI** (Message Passing Interface):
- Used for multi-node/multi-GPU coordination
- Each MPI rank runs the simulation independently on its assigned GPU
- MPI_Gatherv used to gather results from all ranks to rank 0 for reporting
- MPI_Barrier for synchronization between phases

**CUDA** (GPU Acceleration):
- Main simulation kernel (`simKernel`) runs on GPU with one thread per element
- Double-buffering (ping-pong) with device-to-device copies for buffer swapping
- Optimized with 256-thread blocks and `-O3` compilation

**OpenMP** (CPU Parallelization):
- Mesh building uses `#pragma omp parallel for collapse(2)` for the 2D grid construction
- Element initialization uses `#pragma omp parallel for`
- Validation uses OpenMP reductions for parallel sum/max/min computations

### Key Design Decisions
- Each MPI rank uses a different GPU (`rank % 4` for round-robin across 4 GPUs)
- nvcc compiles the `.cpp` file directly (set via `set_source_files_properties`)
- CUDA architecture set to 86 (RTX 3090)
- All ranks produce identical results (verified by matching hashes)
