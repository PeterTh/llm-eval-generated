The MPI parallelization is complete and fully tested. Here's a summary of the changes:

## Changes Made

### `cahn_hilliard.cpp`
- **MPI initialization**: Added `MPI_Init`/`MPI_Finalize` and rank/size queries
- **Domain decomposition**: 3D grid decomposed along Z-axis across MPI ranks, with uneven division handled by distributing remainder slices to first ranks
- **Ghost cells**: Each rank maintains 1 ghost cell layer on each Z-boundary for computing Laplacians at domain boundaries
- **Non-blocking communication**: Uses `MPI_Isend`/`MPI_Irecv` with `MPI_Waitall` for ghost cell exchange between neighboring ranks
- **Local arrays**: Each rank allocates `cold`, `cnew`, and `mu` arrays sized for its local domain + ghost cells
- **Initialization**: Uses global coordinates to ensure deterministic, consistent initialization across ranks
- **Results gathering**: `MPI_Gatherv` collects all rank data to rank 0, reassembling into global layout for validation/results output
- **Rank 0 output**: All printf output (info, results, validation) is restricted to rank 0

### `CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Changed link libraries to `MPI::MPI_CXX m`
