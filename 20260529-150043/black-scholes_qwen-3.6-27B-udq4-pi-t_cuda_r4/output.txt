### Changes Made

**`black_scholes.cpp` → `black_scholes.cu`** (renamed):
- Added `#include <cuda_runtime.h>` for CUDA runtime API
- Added `__device__ __host__` qualifiers to `cumulativeNormal` and `normalPDF` so they compile for both host and device
- Split `blackScholes()` into:
  - `blackScholesDevice()` — `__device__` version using cuMath intrinsics (`erf`, `exp`, `log`, `sqrt`)
  - `blackScholesHost()` — `__host__` version (kept for reference)
- Added `blackScholesKernel` CUDA kernel with one thread per option (256 threads/block)
- Replaced the serial pricing loop with:
  1. GPU memory allocation (`cudaMalloc`)
  2. Host-to-device transfer (`cudaMemcpy`)
  3. Warm-up kernel launch (avoids cold-start timing overhead)
  4. Timed kernel launch with `cudaDeviceSynchronize()`
  5. Device-to-host transfer of results
  6. GPU memory cleanup (`cudaFree`)
- Added `printCudaDevice()` for device info display

- Added `enable_language(CXX CUDA)` for CUDA support
