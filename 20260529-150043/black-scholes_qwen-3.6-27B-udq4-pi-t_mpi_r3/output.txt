## Changes Made

### `black_scholes.cpp`
- **Added `#include <mpi.h>`** for MPI support
- **MPI initialization/finalization**: `MPI_Init` at startup, `MPI_Finalize` at all exit points
- **Block data distribution**: Options are distributed across ranks using a contiguous block scheme. Ranks 0 through `remainder-1` get `baseChunk+1` elements, remaining ranks get `baseChunk` elements (handles non-evenly-divisible counts)
- **Local computation**: Each rank generates its own local options and prices them independently — no communication during the compute phase
- **`MPI_Barrier`** before timing to synchronize all ranks before measurement
- **`MPI_Gatherv`** to gather local results back to rank 0 in correct global order
- **Rank 0 only** handles all output (header, timing, results, validation)

### `CMakeLists.txt`
- Added `find_package(MPI REQUIRED)`
- Changed `target_link_libraries` to link `MPI::MPI_CXX` instead of just `m`
