## Changes Made

### `nbody/nbody.cpp`
- **Added `#include <mpi.h>`** and wrapped the program in `MPI_Init`/`MPI_Finalize`
- **Block distribution**: Bodies are split contiguously across MPI ranks (ranks 0..remainder-1 get one extra body for non-divisible counts)
- **Initialization**: Rank 0 initializes all bodies with the original `randomizeBodies` (preserving exact reproducibility), then `MPI_Scatterv` distributes them
- **Simulation loop** (per step):
  1. `MPI_Allgatherv` gathers all body states to every rank
  2. Each rank computes forces on its **local bodies** against **all bodies** (O(N²/P) compute per rank)
  3. Each rank integrates its local bodies
- **Results/Validation**: `MPI_Gatherv` collects all bodies back to rank 0 for printing results and validation
- Only rank 0 performs I/O (printf, results, validation output)

### `nbody/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Linked `${MPI_CXX_LIBRARIES}` and included `${MPI_CXX_INCLUDE_DIRS}`
