## Changes Made

### `roomsim/CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)` 
- Changed `target_link_libraries` to link `OpenMP::OpenMP_CXX` instead of just `m`

### `roomsim/roomsim.cpp` — 7 edits

1. **Added `#include <omp.h>`** for OpenMP support

2. **Area computation** (init): Parallelized with `#pragma omp parallel for schedule(static)` — each triangle's area is independent

3. **`computeKij`**: Removed shared `RandomGenerator& rng` parameter; now creates a local RNG with a deterministic seed derived from `(idxI, idxJ)` pair — ensures thread safety and reproducibility

4. **`computeFormFactors`**: Parallelized with `#pragma omp parallel for schedule(static) collapse(2)` — the `collapse(2)` distributes the full `(i, j)` pair space across threads for maximum load balancing

5. **`computeTimeDelays`**: Parallelized with `#pragma omp parallel for schedule(static) collapse(2)` — each `(i, j)` pair is independent

6. **`runSimulation`**: Parallelized the inner triangle loop with `#pragma omp parallel for schedule(static)` — within each timestep, all triangle computations are independent (they only read from earlier timesteps)

7. **`computeDistances`**: Parallelized with `#pragma omp parallel for schedule(static)` — each triangle's cross-correlation is independent
