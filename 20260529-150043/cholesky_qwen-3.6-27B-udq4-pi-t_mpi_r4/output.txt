The MPI-parallelized Cholesky benchmark is complete. Here's a summary of the changes:

**CMakeLists.txt**: Added `find_package(MPI REQUIRED)` and linked `MPI::MPI_CXX` to the executable.

**cholesky.cpp**: Complete rewrite with MPI distributed memory parallelism:

1. **1D Block-Row Distribution**: The matrix is distributed across MPI ranks, with each rank owning a contiguous block of rows.

2. **Left-Looking Cholesky Algorithm**: For each column j:
   - The owner of row j computes `L[j][j]`
   - Broadcasts row j (columns 0..j) to all ranks via `MPI_Bcast`
   - All ranks compute `L[i][j]` for their local rows using dot products

3. **Matrix Generation**: Rank 0 generates the full matrix (matching the original sequential code) and scatters it to all ranks via `MPI_Scatterv`.

4. **Validation**: Gathers the full L matrix on rank 0 via `MPI_Gatherv`, computes `L * L^T`, and compares with the original matrix.
