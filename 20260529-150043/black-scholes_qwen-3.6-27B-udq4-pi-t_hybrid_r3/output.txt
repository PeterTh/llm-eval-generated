## Architecture

| Layer | Role |
|-------|------|
| **MPI** | Distributes options across ranks (one rank per GPU). Work is chunked evenly with remainder distribution. |
| **CUDA** | Each rank prices its chunk on its local GPU via a kernel with one thread per option (256 threads/block). |
| **OpenMP** | Parallelizes the CPU-side data generation (`#pragma omp parallel for`). |

## Key design decisions

1. **CUDA kernel** (`blackScholesKernel`): One thread per option, using device-side `erff()` for the cumulative normal distribution. This gives massive parallelism on each GPU.

2. **MPI distribution**: Options are split into contiguous chunks across ranks. Each rank generates, prices, and sends back its portion. Results are gathered on rank 0 via `MPI_Gatherv`.

3. **Device selection**: Each MPI rank maps to a unique GPU via `rank % deviceCount` round-robin.

4. **Correctness**: Results are bit-identical across 1 and 4 ranks (verified by matching hash `04c368a4740f9669`).
