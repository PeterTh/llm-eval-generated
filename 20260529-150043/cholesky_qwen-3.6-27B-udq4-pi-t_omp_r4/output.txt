## Changes Made

### `cholesky/cholesky.cpp`
- **Added `#include <omp.h>`** for OpenMP support
- **Restructured Cholesky decomposition** to column-oriented algorithm:
  - Outer loop iterates over columns `j` (sequential dependency preserved)
  - Diagonal element computed with `#pragma omp simd reduction` for vectorization
  - Off-diagonal elements in each column parallelized across rows `i` with `#pragma omp parallel for schedule(static)` + SIMD inner loop
  - Upper-triangle zeroing parallelized with `#pragma omp parallel for`
- **Parallelized matrix generation**:
  - Random matrix B: `#pragma omp parallel for` with per-element independent seeds
  - Matrix multiply A = B*B^T: `#pragma omp parallel for collapse(2)` + SIMD inner loop
  - Diagonal dominance: `#pragma omp parallel for`
- **Parallelized validation**:
  - Matrix multiply L*L^T: `#pragma omp parallel for collapse(2)` + SIMD
  - Error computation: `#pragma omp parallel for reduction(max:maxError, max:relError)`
- Added thread count display in output

### `cholesky/CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)`
- Changed `target_link_libraries` to link `OpenMP::OpenMP_CXX` instead of just `m`

### Key design decisions
- **Column-oriented Cholesky**: Enables parallelism across rows within each column (rows `i > j` are independent once the diagonal is computed)
- **Static scheduling**: Best for the regular, predictable work distribution in Cholesky
- **SIMD + parallel for**: Two-level parallelism - threads across rows, vectorization within dot products
- **collapse(2)** for matrix multiplication: Better load balancing across threads for the (i,j) grid
