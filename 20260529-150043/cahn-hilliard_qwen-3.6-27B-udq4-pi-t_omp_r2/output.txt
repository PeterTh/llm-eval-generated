### Key design choices
- **`collapse(3)`**: Flattens the 3 nested loops into a single iteration space for optimal load balancing across threads
- **`schedule(static)`**: All iterations have equal work, so static scheduling avoids runtime overhead
- **No false sharing**: Each thread writes to distinct array elements (different `idx` values per iteration)
- **Time-stepping loop left serial**: Each timestep depends on the previous, so only the per-step grid operations are parallelized
