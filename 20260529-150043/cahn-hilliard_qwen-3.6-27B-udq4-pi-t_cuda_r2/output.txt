### `cahn_hilliard.cpp` - CUDA GPU Parallelization

**Three CUDA kernels** replacing the sequential loops:
- `initializeConcentrationKernel` - parallel field initialization

- `cahnHilliardUpdateKernel` - parallel concentration update

**Key optimizations:**
- `__device__ inline` Laplacian with `__ldg()` read-only cache for input arrays
- `__restrict__` pointers for alias analysis
- Pointer swapping on GPU (zero-copy buffer exchange between time steps)
- 256-thread blocks for optimal occupancy
- Single `cudaMemcpy` at the end (no per-iteration host transfer)
- `CUDA_CHECK` macro for error handling
