3. **`matrixMultiply`** — Replaced the naive triple loop with a **blocked (tiled) parallel algorithm**:
   - `#pragma omp parallel for schedule(static) collapse(2)` distributes 64×64 output tiles across threads
   - Each thread owns distinct `(ii, jj)` tiles → **zero race conditions** on `C`
   - Inner `kk` loop provides **cache reuse** (reuses blocks of A and B)
   - Innermost `k` loop uses a **local accumulator** (`sum`) for effective **SIMD auto-vectorization**

4. **`validateResult`** — Parallelized with proper `#pragma omp atomic write` for the failure flag and `#pragma omp critical` for printf safety.
