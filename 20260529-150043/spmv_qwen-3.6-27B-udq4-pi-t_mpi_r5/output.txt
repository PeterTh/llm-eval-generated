## Changes Made

### `spmv/spmv.cpp`
- **Added `#include <mpi.h>`** and wrapped the program with `MPI_Init`/`MPI_Finalize`
- **Row-wise distribution**: Matrix rows are partitioned across MPI ranks using balanced block distribution (handles non-even division with `extraRows`)
- **Data partitioning**:
  - **Broadcast** input vector `h_vec` to all ranks (needed since any row can reference any column)
  - **Broadcast** `h_rowDelimiters` to all ranks (small array, needed for partitioning)
  - **Scatterv** `h_val` and `h_cols` to each rank (non-uniform distribution based on row lengths)
- **Local computation**: Each rank runs `spmvLocal()` on its row partition
- **Gatherv** results back to rank 0 for output and validation
- **Timing barriers** (`MPI_Barrier`) ensure all ranks synchronize before/after the timed region
- **Added `spmvLocal()`** function for local SpMV on partitioned data
- All I/O restricted to rank 0 to avoid interleaved output

### `spmv/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` 
- Changed `target_link_libraries` to link `MPI::MPI_CXX`
