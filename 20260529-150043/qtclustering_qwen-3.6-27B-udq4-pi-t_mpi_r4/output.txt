### qtclustering.cpp — MPI Parallelization Strategy

**Core approach**: Parallelize seed evaluation within each clustering iteration across MPI ranks.

1. **Data distribution**: All ranks hold the full point set and a precomputed O(N²) distance matrix (computed on rank 0, then broadcast via `MPI_Bcast`)

2. **Seed distribution**: In each iteration, unclustered seeds are distributed across ranks via round-robin assignment for load balancing

3. **Parallel cluster generation**: Each rank independently generates candidate clusters for its assigned seeds — embarrassingly parallel within the iteration

4. **MPI reduction**: `MPI_Allgather` collects the best `(cardinality, seed)` pair from each rank. The global best is selected by largest cardinality (ties broken by lowest seed index)

5. **Deterministic regeneration**: Since cluster generation is deterministic (same seed + same data = same result), all ranks independently regenerate the winning cluster from the globally agreed seed — no need to communicate variable-length member lists

6. **Synchronization**: `MPI_Barrier` before timing, `MPI_Wtime` for wall-clock measurement
