## Changes Made

### `matmul/matmul.cpp` — Full CUDA rewrite
- **Tiled kernel with shared memory**: 32×32 tiles loaded into `__shared__` memory, reducing global memory traffic by ~32x
- **Bank-conflict-free layout**: Shared memory arrays use `TILE_SIZE + 1` stride to avoid shared memory bank conflicts
- **`__ldg()` read-only cache**: Global loads from input matrices use the L1 read-only cache for faster access
- **Boundary-safe tiling**: Out-of-bounds elements are zeroed, and output is `cudaMemset`-initialized to handle edge tiles correctly
- **Device memory management**: `cudaMalloc`/`cudaMemcpy`/`cudaFree` with error checking via `CUDA_CHECK` macro
- **GPU detection**: Prints the active GPU name at startup

### `matmul/CMakeLists.txt` — CUDA build system
- Added `CUDA` to project languages and `enable_language(CUDA)`
- Auto-detects GPU architecture via `nvidia-smi` (falls back to common archs)
- Marks `matmul.cpp` as CUDA language source (compiled with `nvcc`)
- Links against CUDA runtime (handled automatically by CMake)
