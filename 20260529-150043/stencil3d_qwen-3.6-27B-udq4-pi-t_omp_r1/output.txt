The stencil3d benchmark has been parallelized with OpenMP. Here's a summary of the changes:

### `stencil3d.cpp` — OpenMP parallelization

| Function | Parallelization | Rationale |
|---|---|---|
| `initializeGrid` | `collapse(3)` on all 3 loops | Trivially parallel — each cell writes independently |
| `stencilIteration` (stencil core) | `collapse(3)` on z/y/x loops | Each output cell reads from `input` and writes to `output` independently — no data races |
| `stencilIteration` (boundary copy) | `collapse(2)` on z/y loops | Boundary writes are independent |
| `validateResult` (NaN/Inf check) | `parallel for` with shared flag | Parallel scan for invalid values |
| `validateResult` (min/max) | `parallel for` with `reduction(min/max)` | Standard reduction pattern |

### `CMakeLists.txt` — Build system

- Added `find_package(OpenMP REQUIRED)` 
- Linked `OpenMP::OpenMP_CXX` instead of manual `-fopenmp` flag
