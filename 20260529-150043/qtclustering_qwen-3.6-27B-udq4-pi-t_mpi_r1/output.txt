The MPI parallelization is complete. Here's a summary of the changes:

## Changes Made

### `qtclustering/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)` to locate MPI
- Changed `target_link_libraries` to link `MPI::MPI_CXX` (in addition to `m`)

### `qtclustering/qtclustering.cpp`
- Added `#include <mpi.h>`
- **MPI initialization/finalization** in `main()` with `MPI_Init`/`MPI_Finalize`
- **Data replication**: Points are generated on rank 0 and broadcast to all ranks via `MPI_Bcast`
- **`qtClusteringMPI()`**: New parallel clustering function that:
  - Distributes seed evaluation across MPI ranks at each iteration (balanced workload with remainder handling)
  - Each rank independently generates candidate clusters for its assigned seeds
  - Uses a **two-phase global reduction** to find the best cluster:
    1. `MPI_Allreduce(MPI_MAX)` to find global maximum cardinality
    2. `MPI_Allreduce(MPI_MIN)` for deterministic tie-breaking by seed index
  - `MPI_Bcast` to distribute the winning cluster members to all ranks
  - Synchronized clustered status across all ranks
- **I/O confinement**: All printf output goes through rank 0 only
- **Performance optimizations**: Early exit in `findClosestPoint` when diameter threshold is violated; `std::vector<char>` instead of `bool` for compact storage; `std::move` to avoid copies

### Correctness Verification
- Identical hashes across 1, 2, and 4 MPI ranks for multiple test cases
- Validation passes on all configurations
- Deterministic tie-breaking matches the sequential version exactly
