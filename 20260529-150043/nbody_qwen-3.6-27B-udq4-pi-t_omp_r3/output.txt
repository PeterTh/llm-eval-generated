### `nbody/nbody.cpp` - 5 parallelized regions:

| Function | Parallelization | Technique |
|---|---|---|
| **`computeForces`** | `#pragma omp parallel for` on outer loop + `#pragma omp simd` on inner loop | Each body's force is independent; SIMD vectorizes the N-body inner loop |
| **`integrateBodies`** | `#pragma omp parallel for` | Each body's integration is independent |
| **`computeTotalEnergy` (kinetic)** | `#pragma omp parallel for reduction(+:energy)` | Trivially parallel sum |
| **`computeTotalEnergy` (potential)** | `#pragma omp parallel for reduction(+:energy)` on outer loop | Outer loop parallel with reduction; inner loop remains sequential per-thread |
| **`validateSimulation`** | `#pragma omp parallel for` + `#pragma omp critical` | Parallel check with critical section for first-error reporting |
