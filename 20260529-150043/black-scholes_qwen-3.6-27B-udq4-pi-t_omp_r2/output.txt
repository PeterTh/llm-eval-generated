### `CMakeLists.txt`
1. **Added `find_package(OpenMP REQUIRED)`** — discovers OpenMP on the system
2. **Added `OpenMP::OpenMP_CXX` to `target_link_libraries`** — links the OpenMP runtime (this also implicitly adds `-fopenmp` compile flag via the imported target)

### Design choices
- **`schedule(static)`** — chosen because all iterations have uniform computational cost (each `blackScholes()` call does the same math), making static chunking optimal with minimal overhead
- **No `simd` directive** — the compiler already auto-vectorizes the math inside `blackScholes()` with `-O3 -march=native`; adding `simd` explicitly is redundant
- **No data race concerns** — each thread writes to a unique index in `results[]` and reads from `options[]` which is read-only during the parallel region
- **Unconditional parallelism** — OpenMP is always active (no `#ifdef` guards), as required
