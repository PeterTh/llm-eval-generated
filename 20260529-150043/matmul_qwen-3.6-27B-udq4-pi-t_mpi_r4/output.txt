The MPI-parallelized matmul benchmark is complete and working correctly. Here's a summary of the changes:

## Changes Made

### `matmul/matmul.cpp`
- **MPI initialization**: Uses `MPI_Init_thread` with `MPI_THREAD_MULTIPLE`
- **2D process grid**: Automatically determines a balanced grid (e.g., 4 procs → 2×2, 8 procs → 2×4)
- **Block distribution**: Result matrix C is distributed across processes in 2D blocks. Each process computes only its local C block.
- **Full A and B per process**: Each process stores full A and B (O(N²) init is negligible vs O(N³) multiply), avoiding complex data distribution communication
- **Cache-friendly multiply**: i-k-j loop ordering for better cache reuse on B
- **Timing**: `MPI_Wtime()` with `MPI_Reduce(MPI_MAX)` for consistent wall-clock measurement
- **Result gathering**: `MPI_Gatherv` to root, then rearranges into row-major layout
- **Validation**: Root validates using its locally available full A and B

### `matmul/CMakeLists.txt`
- Added `find_package(MPI REQUIRED)`
- Linked `${MPI_CXX_LIBRARIES}` and included `${MPI_CXX_INCLUDE_PATH}`
