The SpMV benchmark has been successfully parallelized with CUDA. Here's a summary of the changes:

## Changes Made

### `spmv/spmv.cpp`
- Added `#include <cuda_runtime.h>` for CUDA runtime API
- Added two CUDA kernels:
  - **`spmvGpu`** — Standard 1-thread-per-row kernel, optimal for sparse matrices (low nnz/row)
  - **`spmvGpuCooperative`** — Shared-memory cooperative kernel with tree-based reduction, optimal for denser matrices (high nnz/row)
- Added GPU memory management (`cudaMalloc`, `cudaMemcpy`, `cudaFree`)
- Added CUDA stream for async execution
- Added adaptive kernel selection based on max nnz per row (threshold: 64)
- Added `checkCudaError()` helper for error handling
- The CPU `spmvCpu` function is retained for validation reference
- All original semantics preserved: same CLI args, same output format, same validation logic

### `spmv/CMakeLists.txt`
- Added `enable_language(CXX CUDA)` 
- Set `CMAKE_CUDA_ARCHITECTURES 86` (RTX 3090)
- Marked `spmv.cpp` as CUDA source
- Set `CMAKE_CUDA_FLAGS` with `-O3` optimization and host compiler flags
