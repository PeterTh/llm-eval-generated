### Changes made

**`floydwarshall.cpp`** — Three key optimizations:

1. **`#include <omp.h>`** added for OpenMP support

2. **`initializeDistanceMatrix`** — Parallelized with `#pragma omp parallel for schedule(static)`. Uses per-element deterministic seeds (`seed + i`) instead of a shared `rand_r` state, enabling full parallelism without races.

3. **`initializePathMatrix`** — Parallelized with `#pragma omp parallel for schedule(static)` on the outer j-loop.

4. **`floydWarshall`** — The core algorithm parallelized with:
   - **k-row/k-column prefetching**: For each k-iteration, the k-th row and column are loaded into contiguous temporary arrays (`kRow`, `kCol`) with `#pragma omp simd`. This eliminates strided memory access patterns during the main computation.
   - **Thread-level parallelism**: `#pragma omp parallel for schedule(static)` on the i-loop distributes work across cores.
   - **SIMD vectorization**: `#pragma omp simd` on the j-loop enables vector processing of the inner loop with sequential memory access.
   - **Correctness guarantee**: For fixed k, all (i,j) pairs are independent because `dist[i][k]` and `dist[k][j]` are invariant within the k-iteration (since `dist[k][k] == 0`).

**`CMakeLists.txt`** — Added `find_package(OpenMP REQUIRED)` and linked `OpenMP::OpenMP_CXX`.
