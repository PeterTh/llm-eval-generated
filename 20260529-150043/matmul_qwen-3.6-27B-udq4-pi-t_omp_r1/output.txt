### `matmul/matmul.cpp`
1. **Added `#include <omp.h>`** — the OpenMP runtime header

2. **`initMatrix()`** — `#pragma omp parallel for schedule(static)` across the row loop. Each row is independent, so static scheduling gives zero-overhead distribution.

3. **`matrixMultiply()`** — `#pragma omp parallel for collapse(2) schedule(static)` across the i,j loops. This is the key optimization:
   - `collapse(2)` flattens the 2D iteration space into a 1D chunk grid, giving N² independent tasks (each computing one C[i,j] dot product) rather than just N tasks. This provides far better load balancing and scalability, especially on many-core systems.
   - `schedule(static)` avoids dynamic scheduling overhead — the work is perfectly uniform.
   - Each (i,j) pair is fully independent (reads from A/B, writes to a unique C cell), so no race conditions.

4. **Thread count display** — prints `omp_get_max_threads()` so users can see parallelism at a glance.
