## Changes Made

### `cholesky/cholesky.cpp`
1. **Added `#include <omp.h>`** for OpenMP support.

2. **Restructured `choleskyDecomposition`** from row-major to **column-major** order:
   - Outer loop iterates columns `j` (sequential — required by data dependencies)
   - **Off-diagonal elements** in each column (`i > j`) are **parallelized** with `#pragma omp parallel for` — each row is independent
   - **Upper triangular zeroing** is parallelized with `#pragma omp parallel for`
   - Innermost dot products use `#pragma omp simd reduction(+:sum)` for **SIMD vectorization**

3. **Parallelized `generatePositiveDefiniteMatrix`**:
   - Matrix multiplication `A = B * B^T` parallelized across rows with `#pragma omp parallel for`
   - Inner dot products vectorized with `#pragma omp simd`
   - Diagonal dominance addition parallelized

4. **Parallelized `validateCholesky`**:
   - `L * L^T` multiplication parallelized across rows
   - Error computation uses `#pragma omp parallel for reduction(max:maxError,relError)`

5. **Added thread count output**: `printf("OpenMP threads: %d\n", omp_get_max_threads());`

### `cholesky/CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)` and `target_link_libraries(cholesky OpenMP::OpenMP_CXX m)` to link OpenMP unconditionally.
