### qtclustering.cpp
Key changes for MPI parallelism:

1. **Added MPI includes and initialization**: `MPI_Init`, `MPI_Comm_rank`, `MPI_Comm_size`, `MPI_Finalize`

2. **Parameter broadcasting**: Command line args parsed on rank 0, then `MPI_Bcast` to all ranks

3. **Data replication**: All ranks generate identical synthetic data (same seed)

4. **Parallel clustering loop** (`qtClusteringMPI`):
   - **Phase 1**: Rank 0 broadcasts the clustered bitmask and unclustered indices to all ranks
   - **Phase 2**: Seeds distributed via block distribution across ranks; each rank independently generates candidate clusters for its assigned seeds
   - **Phase 3**: `MPI_Gather` collects local best cardinalities and member sizes to rank 0
   - **Phase 4**: Rank 0 determines the global winner (largest cardinality, lower rank wins ties) and broadcasts it
   - **Phase 5**: Winning rank sends its cluster data to rank 0 via `MPI_Send`/`MPI_Recv`
   - **Phase 6**: Rank 0 updates state and broadcasts a continue flag

5. **Output consolidation**: Only rank 0 prints results, validation, and performance metrics
