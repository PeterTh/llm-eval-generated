Done. Here's a summary of the changes:

### `floydwarshall.cpp`
- Added `#include <omp.h>`
- **`floydWarshall()`**: Parallelized the inner `i` loop with `#pragma omp parallel for schedule(static)` for each `k` iteration. The `k` loop remains sequential (required by the algorithm's data dependencies). Key correctness insight: for a fixed `k`, `dist[i][k]` and `dist[k][j]` are invariant within the iteration, so all `(i,j)` pairs update independently. Hoisted `distIK` out of the `j` loop for better performance.
- **`initializeDistanceMatrix()`**: Parallelized both loops with `#pragma omp parallel for schedule(static)`
- **`initializePathMatrix()`**: Parallelized the outer loop with `#pragma omp parallel for schedule(static)`

### `CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)` 
- Linked `OpenMP::OpenMP_CXX` target (with fallback to `-fopenmp` if CMake's OpenMP detection fails)
