### Changes made

**`roomsim/roomsim.cpp`** — 4 parallelized phases:

| Phase | Parallelization | Scheduling | Rationale |
|---|---|---|---|
| **Form factors** (`computeFormFactors`) | `#pragma omp parallel` + `#pragma omp for` | `dynamic, 1` | Each (i,j) pair is independent. Thread-local RNG with per-thread seed (`42 + thread_id * 2654435761`) for deterministic results. Dynamic scheduling handles variable work per triangle. |
| **Time delays** (`computeTimeDelays`) | `#pragma omp parallel for` | `static` | Pure read-only computation, uniform work per iteration |
| **Simulation** (`runSimulation`) | `#pragma omp parallel for` inside timestep loop | `static` | Timesteps must stay sequential (data dependency on prior `radB`), but triangles within a timestep write to distinct `radB[t,i]` indices — no races |
| **Distances** (`computeDistances`) | `#pragma omp parallel for` | `static` | Each triangle's cross-correlation is fully independent |

**`roomsim/CMakeLists.txt`** — Added `find_package(OpenMP REQUIRED)` and linked `${OpenMP_CXX_FLAGS}` / `${OpenMP_CXX_LIBRARIES}`.
