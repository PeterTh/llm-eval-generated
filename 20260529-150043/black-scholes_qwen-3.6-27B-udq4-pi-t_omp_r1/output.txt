Done. Here's a summary of the changes:

### `black_scholes.cpp`
- Added `#include <omp.h>` for OpenMP runtime support
- Parallelized the pricing loop with `#pragma omp parallel for schedule(static)`:
  - Each option is priced independently (embarrassingly parallel — no data dependencies)
  - `schedule(static)` provides optimal load balancing since all iterations have uniform cost
  - Changed loop variable to `long` to satisfy OpenMP's signed index requirement
  - Added thread count reporting via `omp_get_max_threads()`

### `CMakeLists.txt`
- Added `find_package(OpenMP REQUIRED)` to locate OpenMP
- Linked `OpenMP::OpenMP_CXX` to the target (provides both compile flag `-fopenmp` and linker flag)
- Removed redundant manual `-fopenmp` compile option since the imported target handles it
