## Hybrid MPI + OpenMP + CUDA Parallelization

### Architecture
- **MPI**: Domain decomposition along the Z-axis across ranks. Each rank owns a contiguous chunk of Z-slices.
- **CUDA**: All stencil computations (Laplacian, chemical potential, Cahn-Hilliard update) run on GPU kernels. Each rank uses its own GPU (round-robin assignment if more ranks than GPUs).
- **OpenMP**: Parallelizes host-side tasks (halo buffer initialization, result extraction from ghost layout, boundary clamping).

### Key Design Decisions
1. **Z-axis decomposition**: Splits the 3D grid along Z, minimizing communication volume (only XY planes exchanged per rank pair).
2. **Non-blocking MPI**: Uses `MPI_Isend`/`MPI_Irecv` for halo exchange with proper tag matching (tag 100 for upward, tag 200 for downward).
3. **GPU synchronization**: `cudaDeviceSynchronize()` before halo extraction ensures GPU kernels complete before data is read back.
4. **Correct initialization**: Uses global volume and global offset for deterministic pseudo-random initialization across ranks.
