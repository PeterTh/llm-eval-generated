All tests pass. Here's a summary of the OpenMP parallelization changes:

### Changes to `spmv.cpp`

1. **Added `#include <omp.h>`** for OpenMP support

2. **`fill()`** — Parallelized with `#pragma omp parallel for`. Replaced non-thread-safe `rand()` with a per-element deterministic LCG (Knuth multiplier), eliminating data races while maintaining uniform distribution.

3. **`spmvCpu()`** — The main kernel, parallelized with `#pragma omp parallel for schedule(static, 64)`. Each row's dot product is independent, making this embarrassingly parallel. The `static` schedule with chunk size 64 provides good load balancing (rows vary in length for sparse matrices) while minimizing scheduling overhead. Minor optimization: hoisted `rowDelimiters[i]` and `rowDelimiters[i+1]` to local variables.

4. **`verifyResults()`** — Parallelized with `#pragma omp parallel for reduction(+:failures)`. Replaced early-exit pattern (not parallelizable) with a reduction counting failures, which gives equivalent correctness semantics with full parallelism.

### Changes to `CMakeLists.txt`

- Added `find_package(OpenMP REQUIRED)` and linked `OpenMP::OpenMP_CXX` to the target.
