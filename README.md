# LLM Parallelization Evaluation — Generated Code

Raw LLM agent output for each experiment run. Each subdirectory corresponds to one agent invocation and contains the generated parallelized C++ code, agent logs, and token usage information.

Directory naming convention: `{benchmark}_{model}_{parallelization-type}_r{run-number}`

This data was produced as part of a study on evaluating the parallelization capabilities of agentic LLMs.

For full context, experiment scripts, and documentation, see the main repository:
**[llm-eval-experiment](https://github.com/PeterTh/llm-eval-experiment)**
